# Tasks - 学员网站端 我的题库&我的分享 功能开发

## 开发任务清单

- [ ] Task 1: 修改 tab-nav-bar，添加"我的题库"和"我的分享"导航项

  - 为新tab添加对应的iconify图标

- [ ] Task 2: 创建"我的题库" tab-panel (panel-question-bank)

  - 已刷专题列表（5个示例专题）

- [ ] Task 3: 创建"我的分享" tab-panel (panel-shares)
  - 分享统计区（红橙渐变主题）
  - 分享奖励卡片
  - 分享记录列表（4个示例记录）
  - 分享规则说明区
  - 添加对应的CSS样式

- [ ] Task 4: 实现分享弹窗功能
  - 分享弹窗HTML结构
  - 弹窗显示/隐藏动画
  - 分享渠道按钮（微信、朋友圈、QQ、QQ空间、复制链接）
  - Toast提示组件

- [ ] Task 5: 添加JavaScript交互逻辑
  - Tab切换功能（复用现有switchTab函数）
  - 分享弹窗打开/关闭函数
  - 复制链接功能
  - Toast提示显示函数

- [ ] Task 6: 样式适配和响应式调整
  - 确保新组件在design-tokens.css变量下正常显示
  - 响应式布局测试（桌面、平板、移动端）
  - 与现有风格的视觉一致性检查

## Task Dependencies

- Task 2, 3 依赖 Task 1（需要先添加tab导航）
