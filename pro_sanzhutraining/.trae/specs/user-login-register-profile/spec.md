# 学员网站端 - 登录/注册/个人信息页面

## Why

完善学员网站端的用户体系，提供完整的登录、注册流程和个人信息管理功能，提升用户体验和网站专业度。

## What Changes

- 新增 `login.html` - 登录页面
- 新增 `register.html` - 注册页面
- 新增 `profile.html` - 个人信息页面
- 修改 `user-center.html` - 添加登录状态判断

## Impact

- Affected specs: 用户体系、个人中心
- Affected code:
  - html/website/eldercare/login.html
  - html/website/eldercare/register.html
  - html/website/eldercare/profile.html
  - html/website/eldercare/user-center.html

---

## ADDED Requirements

### Requirement: 登录页面 (login.html)

**功能特性：**
1. **页面布局**
   - 居中卡片式设计，最大宽度600px
   - 左侧/顶部品牌区域（Logo、品牌名、口号）
   - 右侧/主体区域（表单）

2. **表单元素**
   - 手机号/用户名输入框（带图标）
   - 密码输入框（带显隐切换按钮）
   - 记住登录状态复选框
   - 忘记密码链接

3. **操作按钮**
   - 登录按钮（渐变绿色背景）
   - 微信授权登录按钮
   - 隐私协议勾选框

4. **交互功能**
   - 输入时清除错误提示
   - 表单验证（必填项检查）
   - 密码显隐切换
   - 登录成功弹窗（2秒后自动跳转）
   - 加载状态（按钮loading动画）

5. **已登录状态处理**
   - 检测sessionStorage中的登录状态
   - 已登录用户直接跳转到首页

### Requirement: 注册页面 (register.html)

**功能特性：**
1. **页面布局**
   - 与登录页面风格一致
   - 居中卡片式设计

2. **表单元素**
   - 手机号输入框（带获取验证码按钮）
   - 验证码输入框（60秒倒计时）
   - 密码输入框（8-20位，包含字母和数字）
   - 确认密码输入框
   - 用户协议勾选框

3. **交互功能**
   - 发送验证码（60秒倒计时）
   - 密码强度检测提示
   - 确认密码一致性验证
   - 注册成功弹窗

### Requirement: 个人信息页面 (profile.html)

**功能特性：**
1. **页面布局**
   - 使用现有user-center.html的设计风格
   - 顶部用户头像和信息区域
   - 下方个人信息表单

2. **个人信息表单**
   - 头像上传/预览
   - 姓名
   - 手机号（不可修改，显示脱敏）
   - 邮箱
   - 性别（单选）
   - 出生日期
   - 所在地区（省市区联动）
   - 个人简介

3. **操作按钮**
   - 保存修改按钮
   - 修改密码按钮
   - 退出登录按钮

4. **交互功能**
   - 头像点击预览
   - 表单数据预填充
   - 保存成功提示

## UI/UX 设计规范

### 视觉风格
- 使用 design-tokens.css 中的设计令牌
- 绿色主题色：#2e9e5a（主色）、#3db870（浅绿）
- 保持与整个网站视觉一致性

### 布局规范
- 登录/注册页面：居中卡片，最大宽度600px
- 个人信息页面：顶部banner + 居中内容区，最大宽度960px

### 响应式断点
- 桌面端（>992px）：左右分栏布局
- 平板端（768-992px）：单列居中
- 移动端（<768px）：全宽表单

### 动画效果
- 按钮hover：轻微上浮 + 阴影加深
- 输入框focus：边框颜色变化
- 加载状态：按钮内旋转动画
- 弹窗：淡入 + 缩放动画

## 页面跳转关系

```
首页/用户中心 → [未登录] → 登录页面 → 注册页面
     ↓
个人信息页面 → 退出登录 → 登录页面
```

## 技术实现

- 纯HTML/CSS/JavaScript实现
- 使用Iconify图标库
- 复用design-tokens.css设计变量
- 使用sessionStorage模拟登录状态
- 表单验证使用原生JavaScript
