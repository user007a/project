# 叁竹培训考试模块 - 考试大厅功能 PRD

## Overview
- **Summary**: 构建考试模块的考试大厅、模拟考试、练习模式和错题本功能，包含主入口页面、考试/练习列表、详情页面和在线答题界面；同时更新小程序端导航，将"题库"改为"考试"，"我的题库"改为"我的考试"
- **Purpose**: 为养老护理员提供专业的在线考试和练习平台，支持正式考试、模拟考试、练习模式、错题复习等功能
- **Target Users**: 养老护理员、老年人能力评估师等职业技能培训学员

## Goals
- 完成考试大厅主入口页面开发（5个功能入口）
- 实现考试大厅功能（可考试列表、考题阅览、在线考试）
- 实现模拟考试功能（与考试大厅内容一致，使用模拟数据）
- 实现练习模式功能（练习列表、章节选择、每日20题、收藏功能）
- 实现错题本功能（错题分类、筛选、练习、移除）
- 提供养老护理相关的Mock题目数据
- 更新小程序端导航："题库"→"考试"，"我的题库"→"我的考试"

## Non-Goals (Out of Scope)
- 收藏习题功能（后续迭代）
- 后端API集成（当前使用Mock数据）

## Background & Context
- 现有项目基于HTML/CSS/JavaScript开发，使用Tailwind CSS框架
- 已有question-bank.html和quiz.html作为参考
- 需要保持与现有风格一致的视觉设计
- 参考图片展示了移动端考试、练习和错题本界面的交互模式
- 小程序端现有"题库"入口需要改名为"考试"，"我的题库"改名为"我的考试"

## Functional Requirements
- **FR-1**: 考试大厅主页展示5个功能入口卡片（考试大厅、模拟考试、练习模式、错题本、收藏习题）
- **FR-2**: 考试列表支持筛选和状态标识（已参考、未开始、锁定）
- **FR-3**: 考试详情页展示考试基本信息（总分、题数、时长）
- **FR-4**: 答题界面支持单选题、多选题、判断题、问答题
- **FR-5**: 底部工具栏包含交卷、答题卡、上一题、下一题按钮
- **FR-6**: 计时器功能显示考试剩余时间
- **FR-7**: 答题卡显示答题进度和标记状态
- **FR-8**: 模拟考试功能与考试大厅一致（无计时器限制，练习性质）
- **FR-9**: 练习模式列表展示练习名称和题数，支持筛选
- **FR-10**: 练习详情页面显示章节列表和练习进度
- **FR-11**: 练习模式支持"每日20题"快速练习功能
- **FR-12**: 练习答题页面底部包含收藏按钮
- **FR-13**: 错题本页面展示错题分类（按题型）和数量
- **FR-14**: 错题本支持按分类筛选错题
- **FR-15**: 错题练习页面显示错题内容，底部包含移除、答题卡、上一题、下一题按钮
- **FR-16**: 错题本支持"全部练习"功能
- **FR-17**: 小程序端导航更新：底部导航"题库"改为"考试"，对应页面标题更新
- **FR-18**: 小程序端"我的题库"入口改为"我的考试"

## Non-Functional Requirements
- **NFR-1**: 响应式设计，支持移动端和桌面端
- **NFR-2**: 答题界面加载时间 < 1秒
- **NFR-3**: 支持离线答题状态保存（sessionStorage）
- **NFR-4**: 视觉风格与现有项目保持一致

## Constraints
- **Technical**: HTML5/CSS3/JavaScript, Tailwind CSS 3.x
- **Business**: 养老护理职业技能培训领域
- **Dependencies**: Iconify图标库、Tailwind CDN

## Assumptions
- 用户已登录系统
- Mock数据模拟真实养老护理考试题目
- 考试进度保存在本地存储

## Acceptance Criteria

### AC-1: 考试大厅主页展示
- **Given**: 用户进入题库模块
- **When**: 加载考试大厅页面
- **Then**: 显示5个功能入口卡片（考试大厅、模拟考试、练习模式、错题本、收藏习题）
- **Verification**: `human-judgment`

### AC-2: 考试列表展示
- **Given**: 用户点击"考试大厅"入口
- **When**: 进入可考试列表页面
- **Then**: 显示考试列表，包含考试名称、总分、题数、状态标签
- **Verification**: `human-judgment`

### AC-3: 筛选功能
- **Given**: 考试列表页面已加载
- **When**: 用户点击筛选按钮
- **Then**: 显示筛选选项（全部、未开始、已参考）
- **Verification**: `programmatic`

### AC-4: 答题界面
- **Given**: 用户选择一个考试并开始
- **When**: 进入答题页面
- **Then**: 显示题目内容、选项、计时器、底部工具栏
- **Verification**: `human-judgment`

### AC-5: 单选题答题
- **Given**: 当前题目为单选题
- **When**: 用户点击选项
- **Then**: 选项被选中，答案保存到本地存储
- **Verification**: `programmatic`

### AC-6: 多选题答题
- **Given**: 当前题目为多选题
- **When**: 用户点击多个选项
- **Then**: 多个选项可同时选中，答案保存到本地存储
- **Verification**: `programmatic`

### AC-7: 问答题答题
- **Given**: 当前题目为问答题
- **When**: 用户在输入框输入答案
- **Then**: 答案实时保存到本地存储
- **Verification**: `programmatic`

### AC-8: 答题卡功能
- **Given**: 用户点击底部"答题卡"按钮
- **When**: 弹出答题卡弹窗
- **Then**: 显示所有题目状态（已答、未答、标记），可跳转任意题目
- **Verification**: `human-judgment`

### AC-9: 交卷功能
- **Given**: 用户点击"交卷"按钮
- **When**: 确认交卷后
- **Then**: 显示考试成绩和答案解析
- **Verification**: `human-judgment`

### AC-10: 计时器功能
- **Given**: 考试开始
- **When**: 计时器倒计时
- **Then**: 实时显示剩余时间，超时自动交卷
- **Verification**: `programmatic`

### AC-11: 模拟考试功能
- **Given**: 用户点击"模拟考试"入口
- **When**: 进入模拟考试列表
- **Then**: 功能与考试大厅一致，但无时间限制
- **Verification**: `human-judgment`

### AC-12: 练习模式列表
- **Given**: 用户点击"练习模式"入口
- **When**: 进入练习列表页面
- **Then**: 显示练习名称和题数，支持筛选
- **Verification**: `human-judgment`

### AC-13: 练习详情页面
- **Given**: 用户选择一个练习
- **When**: 进入练习详情页面
- **Then**: 显示章节列表、练习进度和"每日20题"按钮
- **Verification**: `human-judgment`

### AC-14: 练习答题界面
- **Given**: 用户开始练习
- **When**: 进入练习答题页面
- **Then**: 底部工具栏包含收藏、答题卡、上一题、下一题按钮
- **Verification**: `human-judgment`

### AC-15: 收藏功能
- **Given**: 用户点击练习答题页面的收藏按钮
- **When**: 题目被收藏
- **Then**: 题目保存到收藏列表，图标变为已收藏状态
- **Verification**: `programmatic`

### AC-16: 错题本页面展示
- **Given**: 用户点击"错题本"入口
- **When**: 进入错题本页面
- **Then**: 显示错题分类（按题型）和数量，每个分类有"去练习"按钮
- **Verification**: `human-judgment`

### AC-17: 错题本筛选功能
- **Given**: 用户点击错题本页面的筛选按钮
- **When**: 弹出筛选选项
- **Then**: 显示按分类筛选（全部、单选题、多选题等）
- **Verification**: `programmatic`

### AC-18: 错题练习界面
- **Given**: 用户点击"去练习"或"全部练习"按钮
- **When**: 进入错题练习页面
- **Then**: 显示错题内容，底部工具栏包含移除、答题卡、上一题、下一题按钮
- **Verification**: `human-judgment`

### AC-19: 错题移除功能
- **Given**: 用户在错题练习页面点击"移除"按钮
- **When**: 确认移除后
- **Then**: 错题从错题本中移除
- **Verification**: `programmatic`

### AC-20: 全部练习功能
- **Given**: 用户点击底部"全部练习"按钮
- **When**: 进入错题练习
- **Then**: 按顺序练习所有错题
- **Verification**: `human-judgment`

### AC-21: 小程序端底部导航更新
- **Given**: 用户打开小程序
- **When**: 查看底部导航栏
- **Then**: "题库"按钮已改为"考试"，图标保持不变
- **Verification**: `human-judgment`

### AC-22: 小程序端个人中心入口更新
- **Given**: 用户进入个人中心页面
- **When**: 查看功能入口
- **Then**: "我的题库"已改为"我的考试"
- **Verification**: `human-judgment`
