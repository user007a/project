# 叁竹培训系统 - 数据库脚本生成计划

## 一、需求分析

### 1.1 业务模块概览

根据需求规格说明书和已实现的HTML页面，系统包含以下核心业务模块：

| 模块名称 | 说明 | 表前缀 | HTML文件 |
| :--- | :--- | :--- | :--- |
| 后台管理 | 管理员、角色、权限、部门 | `admin_` | user-management.html, role-permission.html, department-management.html |
| 学员管理 | 学员信息、资料、教育/培训经历、材料 | `user_` | student-list.html, profile.html |
| 课程管理 | 课程、章节、课时、分类、收藏 | `course_` | course-list.html, course-detail.html, chapter-form.html |
| 讲师管理 | 讲师信息 | `teacher_` | teacher-list.html, teacher-edit.html |
| 订单管理 | 订单、退款、发票 | `order_` | order-list.html, refund-list.html, invoice-list.html |
| 题库管理 | 题目、专题、答题记录、错题 | `question_` | question-bank.html, quiz.html |
| 证书管理 | 证书、申请记录 | `certificate_` | certificate-manage.html, certificate-list.html |
| 学习管理 | 学习记录、笔记 | `study_` | study-record.html, learn.html |
| 资讯管理 | 资讯、分类 | `news_` | article-list.html, article-category.html |
| 机构管理 | 子机构 | `institution_` | institution-management.html |
| 分享管理 | 分享记录 | `share_` | share-list.html, my-shares.html |
| Banner管理 | 轮播图 | `banner_` | slider-list.html |
| 系统设置 | 系统配置、消息、支付、短信 | `system_` | system-settings.html, message-center.html, payment-settings.html, sms-settings.html |

### 1.2 数据库设计原则

1. **软删除**: 所有业务表均使用 `is_del` 字段标记删除状态，`0` 表示正常，`1` 表示已删除
2. **审计字段**: 所有业务表均包含 `create_time` 和 `update_time` 字段
3. **数据类型**: 使用MySQL原生数据类型，避免使用数据库特有类型
4. **索引**: 为常用查询字段创建索引
5. **外键**: 建立必要的外键约束保证数据完整性
6. **业务前缀**: 表名采用业务模块前缀命名规范
