# 菜单结构修改计划

## 任务概述
将后台管理端的侧边栏菜单从原有结构修改为新结构，涉及26个HTML文件的侧边栏菜单修改。

## 原有菜单结构
1. **工作台** (dashboard.html)
2. **学员中心**：学员管理、证书管理、证书查询、学习记录
3. **课程中心**：课程管理、课程分类、讲师管理、课程分享
4. **订单中心**：订单管理、退款管理、发票管理
5. **题库中心**：题库管理（将被删除）
6. **内容中心**：资讯管理、资讯分类
7. **系统设置**：用户管理、消息管理、基础设置、支付配置、短信配置、角色权限

## 新菜单结构
1. **工作台** (dashboard.html)
2. **学员中心**：学员管理、学习记录
3. **课程中心**：课程管理、课程分享、题库管理、课程分类
4. **讲师中心**：讲师管理（新增）
5. **订单中心**：订单管理、退款管理、发票管理
6. **证书中心**：证书管理、证书查询（新增）
7. **内容中心**：资讯管理、资讯分类
8. **系统设置**：用户管理、角色权限、基础设置、消息管理、支付配置、短信配置

## 实施步骤

### 步骤1：创建新菜单模板
根据新结构创建一个标准的菜单HTML代码块，包含：
- 7个菜单组（删除题库中心）
- 每个菜单组的图标和链接
- 确保高亮当前页面

### 步骤2：批量修改所有HTML文件
使用SearchReplace工具批量替换每个文件中的菜单结构：
1. 删除原有的"学员中心"中的证书管理、证书查询链接
2. 删除原有的"课程中心"中的讲师管理链接
3. 在"课程中心"中添加题库管理链接
4. 在"课程中心"中保留课程分享链接
5. 删除整个"题库中心"菜单组
6. 在"内容中心"之前插入新的"讲师中心"菜单组
7. 在"内容中心"之后插入新的"证书中心"菜单组
8. 调整"系统设置"中菜单项的顺序

### 步骤3：验证和测试
1. 确保所有链接都指向正确的文件
2. 确保当前页面的菜单高亮正确
3. 测试菜单展开/折叠功能
4. 检查是否有遗漏的菜单项

## 注意事项
1. 每个文件的侧边栏菜单结构基本相同，可以批量处理
2. 需要确保每个文件中当前页面对应的菜单项有"bg-[#1890FF] text-white rounded-md"样式
3. 图标使用iconify组件，确保图标名称正确
4. 文件路径使用相对路径（同一目录下）
