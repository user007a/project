## 1. 系统概述

### 1.1 项目背景

叁竹培训是一个专注于**养老行业职业培训与技能认证**的在线教育平台。平台提供养老护理员、老年人能力评估师、健康照护师、营养配餐员等专业方向的在线课程、题库练习、证书认证等一站式培训服务。

### 1.2 系统定位

平台由四端组成：

| 端 | 定位 | 目标用户 |
|----|------|---------|
| **移动端（Mobile）** | 学员学习主阵地 | 学员（手机端） |
| **网站端（Website）** | 品牌展示、课程选购 | 潜在学员、已注册学员（PC端） |
| **后台管理端（Backhand）** | 平台运营管理 | 管理员、运营人员 |
| **数据驾驶舱（Datacockpit）** | 数据可视化管理 | 管理者、决策层 |

### 1.3 核心业务闭环

```
学员注册/登录 → 浏览课程 → 购买/报名 → 视频学习 → 题库刷题 → 考试评测 → 获得证书 → 分享推广
                                                                          ↓
                          管理员：用户管理、课程管理、订单管理、证书管理、数据分析
```

## 2. 用户角色体系

### 2.1 角色定义

| 角色 | 权限范围 | 端入口 |
|------|---------|--------|
| **学员** | 浏览课程、购买、学习、刷题、查看证书 | 移动端 + 网站端 |
| **讲师** | 授课、查看自己课程数据 | 后台管理端（受限） |
| **运营操作员** | 日常运营：学员管理、订单管理、内容管理 | 后台管理端 |
| **超级管理员** | 全部权限：用户管理、系统配置、权限管理 | 后台管理端 |
| **管理者/决策层** | 查看全局数据、趋势分析 | 数据驾驶舱 |

### 2.2 RBAC 权限模型

后台管理系统采用基于角色的访问控制（RBAC），预置两种角色：

- **超级管理员**：全部模块的全部操作权限
- **运营数据员**：学员管理（查看+编辑）、课程管理（仅查看）、订单管理（仅查看）、资讯管理（仅查看）、题库管理（CRUD），**无系统设置权限**

### 2.3 登录方式

- **手机号/用户名 + 密码** 登录（所有端通用）
- **微信授权登录**（移动端、网站端）
- **记住登录状态**（网站端 7 天免登录、移动端记住登录状态）
