## 2. 产品概述

### 2.1 产品定位

叁竹培训在线学习平台是面向养老行业从业人员的**全品类一站式在线培训平台**，覆盖老年人能力评估师、养老护理员、健康照护师、营养配餐员等多个工种的课程学习、在线刷题全链路。平台以**微信小程序为核心学习入口**，PC端定位为报名转化与机构管理工具，后台管理系统支撑全平台运营。

### 2.2 目标用户

| 用户类型 | 描述 | 核心诉求 |
|----------|------|----------|
| 机构管理员 | 培训学校/养老机构管理团队，1-5人，35-55岁，中低数字化能力 | 统一管理学员、学时合规、降本增效 |
| 学员 | 在职转岗人员，主要30-50岁，80%+使用手机端学习 | 碎片化学习、学时合规、在线刷题、拿证上岗 |
| 访客 | 求职者、HR/政府人员 | 了解培训信息、评估平台可信度 |

### 2.3 产品价值

- **对学员**：打破数字鸿沟，提供碎片化的在线学习体验，让养老从业者轻松完成培训、刷题、考证全流程
- **对机构**：一站式学员管理、学时合规报表、财务对账，替代散落的Excel和纸质台账
- **对行业**：填补养老行业场景化在线培训空白，推动从业人员专业化、标准化

### 2.4 核心目标

1. **学习闭环目标**：学员从注册→购课→学习→刷题→拿证全链路线上完成
2. **合规保障目标**：学时记录100%符合民政部门监管要求，支持一键导出合规报表
3. **用户体验目标**：小程序核心操作≤3步完成，首次购课完成率≥40%

## 6. 用户故事

### US-01 机构管理员·学时合规报表
> 作为机构管理员，我希望一键导出学时合规报表（按工种、按学员），以便向民政部门提交培训记录，避免手工汇总出错。

**验收标准**
- Given 学员完成课程学习，When 管理员选择工种+时间范围点击"导出报表"，Then 系统生成Excel文件，包含学员姓名、工种、课程名、累计学时、完成状态
- 报表数据与学员实际学习记录100%一致

### US-02 学员·碎片化学学习
> 作为40岁的在职转岗学员，我希望在午休时用手机小程序打开课程视频，自动从上次位置继续播放，学完一节（≤15分钟）后学时自动记录，不用反复找进度。

**验收标准**
- Given 学员上次观看到第7分43秒退出，When 重新打开该课程，Then 视频在7分43秒处自动续播
- 单个视频切片≤15分钟，学时在视频播放完成后自动累加

### US-03 学员·考前刷题
> 作为备考养老护理员的学员，我希望在手机上按章节刷题，做错的题自动进入错题本，考前可以集中复习错题，提高通过率。

**验收标准**
- Given 学员答错一道题，When 查看答案解析后，Then 该题自动加入错题本
- Given 学员打开错题本，When 选择"重新练习"，Then 系统呈现所有错题供逐题练习，答对后可移出错题本

### US-04 机构管理员·多工种课程管理
> 作为机构管理员，我希望不同工种的课程独立分类管理，各自设置学时要求，避免课程混乱，学员也能按工种快速找到所需课程。

**验收标准**
- Given 管理员在后台创建"养老护理员"工种分类，When 添加课程时选择该分类，Then 该课程仅出现在"养老护理员"课程列表
- 不同工种的学时要求可独立配置

### US-05 学员·课程购买
> 作为学员，我希望在手机上3步内完成课程购买（选课→确认→支付），用微信支付快速付款，不用跳转多个页面。

**验收标准**
- Given 学员在课程详情页点击"立即购买"，When 进入确认页确认订单后点击"微信支付"，Then 唤起微信支付完成付款，≤3步完成
- 支付成功后自动跳转至课程学习页

### US-06 访客·了解平台
> 作为求职者，我希望在官网首页快速了解培训工种、课程优势、证书权威性，并有免费试听入口，帮助我决定是否报名。

**验收标准**
- Given 访客打开PC官网首页，When 浏览首屏内容，Then 可看到：培训工种列表、热门课程卡片（含免费试听标签）、证书权威性说明
- 免费试听视频无需登录即可播放（限1节）

### US-07 机构管理员·学员唤醒
> 作为机构管理员，我希望系统能自动识别7天未学习的学员并推送微信消息提醒，帮助提升课程完成率，减少学员流失。

**验收标准**
- Given 学员连续7天未登录/未学习，When 管理员开启"学员唤醒"功能，Then 系统通过微信服务通知推送提醒消息
- 消息包含：学员姓名、未学课程名、学习进度百分比、一键继续学习链接

### US-08 学员·笔记功能
> 作为学员，我希望在学习过程中随时记录笔记，笔记能关联到具体课程章节，方便后续复习查找。

**验收标准**
- Given 学员在视频播放页点击"添加笔记"，When 输入笔记内容并保存，Then 笔记自动关联当前播放位置和章节
- Given 学员在笔记列表点击某条笔记，Then 自动跳转至对应课程章节

### US-09 学员·考试答题
> 作为学员，我希望在线答题支持单选、多选、判断题型，即时反馈答案对错，并有详细解析帮助理解。

**验收标准**
- Given 学员选择答案后，When 点击下一题或提交，Then 即时显示正确答案和详细解析
- 多选题需选中所有正确答案才算答对

### US-10 机构管理员·发票管理
> 作为机构管理员，我希望能统一管理学员的发票申请，支持审核、驳回、下载等操作。

**验收标准**
- Given 学员提交发票申请，When 管理员审核通过，Then 系统生成电子发票并支持下载
- 发票状态流转：待审核→已通过→已开票；待审核→已驳回（可重新提交）
