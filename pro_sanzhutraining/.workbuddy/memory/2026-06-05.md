# 2026-06-05 工作日志

## CDN 本地化（全量 62 个 HTML 文件）

### 问题
项目所有 HTML 引用 3 个海外 CDN，因网络不通导致样式和图标完全失效：
- `cdn.tailwindcss.com` → Tailwind CSS Play CDN
- `code.iconify.design/3/3.1.1/iconify.min.js` → Iconify 图标库
- `cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js` + `china.js` → ECharts 数据大屏

### 解决方案
创建 `html/libs/` 目录，通过 npmmirror 下载并提取以下本地文件：

| 文件 | 来源 | 大小 |
|------|------|------|
| `tailwindcss-browser.js` | @tailwindcss/browser@4.3.0 (v4) | 273KB |
| `iconify.min.js` | @iconify/iconify@3.1.1 | 26KB |
| `echarts.min.js` | echarts@5.5.0 | 1MB |
| `echarts-china.js` | echarts@4.9.0 map/js/china.js | 63KB |

### 关键技术细节
- Tailwind CDN 是 v3 Play CDN，而本地化改用 v4 @tailwindcss/browser
- v4 不支持 `tailwind.config = {}` 语法，改用 `<style type="text/tailwindcss">` + `@theme {}` 注入自定义颜色
- 自定义颜色：brand 系（#2e9e5a 等）、accent 系（orange/blue/red/purple/cyan）
- 批量替换脚本：`html/libs/patch-cdn.js`（Node.js）
- 修改了 58/62 个文件（4个无CDN引用跳过）

### 下载方式
- 所有 CDN 域名均不通，通过 `registry.npmmirror.com` 下载 .tgz 包
- 用 Node.js zlib + 手动解析 tar 格式提取文件（tar 命令不支持 Windows 盘符路径）
- curl 需加 `-k` 跳过 SSL 证书验证（本地吊销服务器脱机）
