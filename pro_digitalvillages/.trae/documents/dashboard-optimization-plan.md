# 数字乡村大屏端（Dashboard）优化建议

## 一、现状概述

经过对需求说明书 5.1 节与 `html/dashboard/` 下代码的逐行比对，当前大屏端在视觉完成度上已有较好基础（苹果绿浅色主题、圆角卡片、Font Awesome 图标、SVG 图表），但在**布局结构、交互功能、数据刷新机制、需求对齐精度**四个维度存在系统性偏差。

**核心差距**：需求要求五列布局（15%/20%/30%/20%/15%），当前实现为三列布局。

---

## 二、布局结构优化

### 2.1 具体偏差

| 项目 | 需求要求 | 当前实现 | 偏差 |
|------|----------|----------|------|
| 顶部标题栏高度 | 80px | 72px (`dashboard.css`) | 中 |
| 内容区列数 | 五列（15%/20%/30%/20%/15%） | 三列 flex:3/4/3 (`dashboard.css`) | **高** |
| 村情总览布局 | 左5张卡片+右概要文字+特色产业 | 8 KPI横排+地图+底部三列 | **高** |

### 2.2 优化方案

**A. 标题栏高度修正**：`.header` 的 `height` 从 72px 改为 80px，同步校验 `main-content` 剩余空间。

**B. 新增 `.layout-five` 五列布局**：替代现有 `.layout-three`，按需求比例分配宽度。各列纵向排列 `.panel`。

**C. 村情总览模块重构（偏差最大）**：
- 移除当前的 8 卡片横排、中间地图区域、底部三列（人口结构/村两委）、右侧公告栏
- 重写为：左侧 5 张 KPI 卡片（总人口、总户数、党员人数、耕地面积、村集体年收入），右侧上半村庄概要文字介绍（自动滚动+悬停暂停），右侧下半特色产业图标列表（最多6个+展开按钮）

## 四、数据刷新机制

### 4.1 差距

需求要求默认每5分钟自动刷新、刷新失败保留数据并显示提示条。当前实现为纯静态硬编码，无任何刷新逻辑。

### 4.2 方案

**A. 引入 `DataService` 模块**：
- `config`: `{ refreshInterval: 300000, staleThreshold: 1800000 }`
- `fetchSection(sectionId)`: 调用 API 获取指定维度数据
- `startAutoRefresh()` / `stopAutoRefresh()`
- `renderSection(sectionId, data)`: 数据驱动的 DOM 渲染

**B. 刷新失败处理**：不修改现有 DOM，显示橙色提示条"数据刷新失败，正在显示上次更新数据"+重试按钮。

**C. 过渡策略**：先将硬编码数据抽取到 `mock-data.js`，`fetchSection` 开发模式返回 mock 数据，预留 API 地址常量。

## 六、视觉效果优化 -- 引入 ECharts

### 6.1 当前问题

所有图表为手写 CSS/SVG，存在交互能力不足、数据绑定困难、Tooltip 精度低、可维护性差等问题。

### 6.2 方案

**推荐引入 ECharts 5.x**：支持联动交互（`connect`/`dispatchAction`）、原生 tooltip、大屏模式、数据刷新 `setOption`。

**图表迁移映射**：

| 当前实现 | ECharts 替代 |
|----------|-------------|
| CSS `.bar-chart` | `echarts.bar` |
| SVG `.ring-chart` | `echarts.pie`（内外径） |
| SVG `.line-chart` | `echarts.line` |
| CSS `.funnel-chart` | `echarts.funnel` |
| SVG `.gauge-chart` | `echarts.gauge` |
| CSS `.h-bar-chart` | `echarts.bar`（horizontal） |

**保留手写方案**：KPI 卡片、进度条、排行榜、日历、时间轴、设施列表、通知公告列表。

## 七、代码架构优化

### 7.1 当前问题

- HTML 单文件约 2150 行，所有 section 硬编码
- 数据与视图深度耦合（数据写在 `style`/`data-tip`/文本中）
- `openKpiModal`/`closeKpiModal` 为全局函数污染
- CSS 单文件 2244 行缺少模块划分

### 7.2 建议文件结构

```
html/dashboard/
  index.html              -- 骨架结构（header + section 容器 + modal）
  css/
    dashboard.css         -- 全局变量、布局、通用组件
    dashboard-sections.css -- 各 section 特有样式
  js/
    dashboard.js          -- 入口：Tab/全屏/轮播/缩放
    data-service.js       -- 数据获取/缓存/刷新
    render-overview.js    -- 村情总览渲染
    render-industry.js    -- 产业兴旺渲染
    render-ecology.js     -- 生态宜居渲染
    render-culture.js     -- 乡风文明渲染
    render-governance.js  -- 治理有效渲染
    render-prosperity.js  -- 生活富裕渲染
    components.js         -- 通用组件（Modal/Tooltip/AutoScroll）
    mock-data.js          -- 开发阶段模拟数据
```

### 7.3 关键改进

- **数据驱动渲染**：section 容器只保留空框架，内容由 JS 根据 mock/API 数据动态生成
- **统一组件封装**：`DashboardComponents.createBarChart()` / `createRingChart()` / `openModal()` 等
- **事件总线**：`EventBus.on/emit/off` 解决跨组件联动（地图点击 --> 列表高亮）
- **消除全局函数**：`openKpiModal` 移入命名空间或 IIFE 内
