## 📌 TL;DR（执行摘要）

本需求规格书定义了一款面向苹果种植企业的 **三端协同（PC + 移动 + 数据大屏）内部管理系统**，核心解决三大痛点：**农事排程低效、农资管理失控、一线执行不可追溯**。

系统以"**一线不用，系统白搭**"为设计哲学，以地块负责者的极简操作体验为生死线，通过三端闭环实现：PC 端编排决策 → 移动端执行反馈 → 大屏端态势感知。

**核心差异化**：

- 🏆 农资全链路管理（采购→退货→使用→库存），行业独家
- 🍎 苹果物候期模型 + 采收管理，从"通用管理"升级为"懂苹果的专业系统"
- 🔗 区块链溯源增强版，产品追溯数据上链，提升消费者信任度
- 🚁 无人机巡园，高空视角+AI识别，全园无死角覆盖
- 🔮 VR基地全景展示，沉浸式园区浏览，远程参观营销赋能
- ⚡ 四层预警体系，响应从小时级降至分钟级

**预期成效**：农事排程时间减少 60%+，记录完整率从 <30% 提升至 >80%，库存准确率从 \~60% 提升至 >95%，预警响应从小时级降至分钟级。

## 一、项目概述

### 1.1 项目背景

中国苹果种植面积约 2900 万亩，年产量超 5000 万吨，是高价值经济作物。然而，农业数字化渗透率仅约 11%，果树种植数字化目标为 45%，存在巨大增量空间。

当前苹果种植企业管理面临的核心挑战：

- **排程低效**：依赖微信群+电话排农事，排程耗时长、执行反馈慢、信息碎片化
- **记录缺失**：农事记录完整率不足 30%，依赖"老经验员工"记忆，人员流动导致知识流失
- **库存失控**：农资库存准确率仅约 60%，采购-使用-库存脱节
- **预警滞后**：设备故障、气象异常等预警响应为小时级，错失最佳处置窗口

### 1.2 项目目标

构建一款以苹果种植为垂直场景的三端协同管理系统，实现：

1. 农事任务从"下达→执行→记录→复盘"全链路数字化闭环
2. 农资从"采购→退货→使用→库存"全链路可控可视
3. 预警从"设置→检测→推送→响应"分钟级闭环
4. 一线操作"拍照即记录，离线不丢失，3 步完核心"

### 1.3 产品定位

**"懂苹果的种植管理平台"** — 以苹果物候期模型为引擎、以生产全过程为关键的垂直专业化管理系统。

## 三、功能需求 — PC 端

### 3.1 企业管理

#### 3.1.1 基地信息管理

**功能描述**：管理企业下所有种植基地的基础信息，支持多基地统一视图与单基地详情。

**用户故事**：

- US-3.1.1-1：作为企业管理者，我要查看所有基地的概况列表，以便快速了解各基地经营规模
- US-3.1.1-2：作为基地管理者，我要编辑本基地的基本信息（面积、位置、品种、树龄），以便保持数据准确

**验收标准**：

- Given 用户具有企业管理者角色，When 进入基地信息页面，Then 可查看所有基地的列表视图，显示基地名称、面积、品种、在岗人数
- Given 用户具有基地管理者角色，When 编辑基地信息，Then 可修改基地名称、地址、面积、品种结构、树龄分布、负责人等字段，保存后即时生效
- Given 用户查看基地详情，When 点击某基地，Then 展示该基地下所有地块的汇总统计（地块数、总面积、产量预估）

**已实现功能**：

- 基地列表展示（名称、面积、品种、在岗人数）
- 基地信息新增、编辑、删除操作
- 基地详情查看（包含地块汇总统计）
- 搜索和筛选功能

**优先级**：P0

#### 3.1.2 地块信息管理

**功能描述**：管理基地下各地块的详细信息，支持地块绘制、属性编辑和状态跟踪。

**用户故事**：

- US-3.1.2-1：作为基地管理者，我要在地图上绘制和编辑地块边界，以便直观管理种植区域
- US-3.1.2-2：作为基地管理者，我要查看各地块的品种、树龄、当前物候期，以便精准安排农事

**验收标准**：

- Given 用户进入地块管理页面，When 选择某基地，Then 显示该基地下所有地块的列表和地图视图，支持切换
- Given 用户具有编辑权限，When 在地图上绘制地块，Then 可通过多边形工具圈定地块范围，并关联品种、树龄、面积等属性
- Given 地块已创建，When 查看地块详情，Then 显示该地块的完整属性、当前物候期、待执行农事、历史产量

**已实现功能**：

- 地块列表展示（名称、所属基地、面积、品种、树龄）
- 地块信息新增、编辑、删除操作
- 地块详情查看（含当前物候期、待执行农事）
- 搜索和筛选功能
- 地块绘制工具入口（地图视图）

**优先级**：P0（地图绘制为 P0，基础信息管理为 P0）

### 3.2 农事管理

#### 3.2.1 生产计划

**功能描述**：创建、编辑和管理农事生产计划，支持按物候期模板自动推荐农事，支持计划分解为可执行任务。

**用户故事**：

- US-3.2.1-1：作为基地管理者，我要基于苹果物候期模板快速生成季度农事计划，以便不遗漏关键农事节点
- US-3.2.1-2：作为基地管理者，我要将计划分解为具体任务并分配到地块和人员，以便精准执行

**验收标准**：

- Given 用户创建新生产计划，When 选择基地和物候期阶段，Then 系统自动推荐该阶段的标准农事项列表（如萌芽期：修剪、追肥、病虫害防治）
- Given 用户确认计划内容，When 点击"分解任务"，Then 可为每项农事指定地块、执行人、执行日期、所需农资，生成任务清单
- Given 生产计划已发布，When 计划中的任务被修改，Then 关联任务自动同步更新，并通知执行人

**已实现功能**：

- 生产计划列表展示（计划名称、基地、周期、状态）
- 计划新增、编辑、删除操作
- 物候期模板选择与农事推荐
- 任务分解与分配功能
- 计划状态管理（草稿/发布/执行中/已完成）
- 统计卡片展示（任务总数、已完成、待执行）

**优先级**：P0

#### 3.2.2 农事记录

**功能描述**：查看、审核和管理所有农事执行记录，支持按地块/人员/时间/类型多维筛选。

**用户故事**：

- US-3.2.2-1：作为基地管理者，我要查看今日所有农事记录的完成情况，以便掌握执行进度
- US-3.2.2-2：作为基地管理者，我要审核地块负责者提交的农事记录，以便确保记录质量

**验收标准**：

- Given 用户进入农事记录页面，When 查看记录列表，Then 显示时间、地块、执行人、农事类型、完成状态，支持按上述维度筛选
- Given 农事记录包含图片，When 点击记录，Then 可查看图片、位置信息、备注详情
- Given 用户具有审核权限，When 审核记录，Then 可标记"通过/退回"，退回时需填写原因，退回的记录在移动端重新显示为待修改

**已实现功能**：

- 农事记录列表展示（时间、地块、执行人、农事类型、状态）
- 记录详情查看（图片、位置、备注）
- 审核功能（通过/退回，退回需填写原因）
- 多维筛选功能（地块、人员、时间、类型）
- 统计卡片展示（今日记录数、待审核数、已通过数）

**优先级**：P0

#### 3.2.3 日常巡园

**功能描述**：管理巡园计划、查看巡园记录和异常上报，支持巡园路线设定。

**用户故事**：

- US-3.2.3-1：作为基地管理者，我要设定巡园路线和打卡点，以便规范巡园覆盖范围
- US-3.2.3-2：作为基地管理者，我要查看巡园异常上报的汇总，以便及时发现和处理问题

**验收标准**：

- Given 用户创建巡园计划，When 设定路线，Then 可在地图上标注必经打卡点，并分配巡园人员和时间
- Given 巡园人员完成巡园，When 管理者查看巡园报告，Then 显示实际路线（GPS 轨迹）、打卡完成率、异常上报列表（含图片和描述）
- Given 巡园存在未打卡点位，When 查看巡园结果，Then 高亮显示遗漏点位

**已实现功能**：

- 巡园记录列表展示（时间、巡园人、路线、状态）
- 巡园详情查看（打卡点完成情况、异常上报列表）
- 异常上报记录管理（图片、描述、处理状态）
- 巡园路线设定（打卡点配置）
- 统计卡片展示（今日巡园次数、异常数、完成率）

**优先级**：P0

### 3.3 农资管理（核心差异化模块）

#### 3.3.1 农资信息

**功能描述**：维护农资基础信息库，包括农药、肥料、工具等分类管理。

**用户故事**：

- US-3.3.1-1：作为基地管理者，我要管理本基地所有农资的品种和规格信息，以便采购和使用时有据可查

**验收标准**：

- Given 用户进入农资信息页面，When 查看列表，Then 按农药/肥料/工具/其他分类展示，显示名称、规格、单位、安全库存线
- Given 用户新增农资，When 填写信息，Then 必填项包括名称、分类、规格、单位，选填项包括安全库存线、供应商、备注

**已实现功能**：

- 农资列表展示（名称、类型、规格、单位、单价、安全库存线、供应商）
- 类型标签分类展示（肥料/农药/工具/其他）
- 农资信息新增、编辑、删除操作
- 搜索和筛选功能

**优先级**：P0

#### 3.3.2 采购信息

**功能描述**：管理农资采购申请、审批和入库全流程。

**用户故事**：

- US-3.3.2-1：作为基地管理者，我要提交农资采购申请并追踪审批状态，以便及时补充库存
- US-3.3.2-2：作为企业管理者，我要审批基地的采购申请，以便控制成本

**验收标准**：

- Given 用户提交采购申请，When 填写采购明细（农资名称、数量、单价、供应商），Then 申请进入审批流程
- Given 采购申请被审批通过，When 确认收货入库，Then 库存自动增加对应数量，采购记录状态更新为"已入库"
- Given 采购申请被退回，When 查看退回原因，Then 可修改后重新提交

**已实现功能**：

- 采购列表展示（采购单号、农资名称、供应商、数量、金额、状态）
- 状态标签展示（待审核/已审核/已入库/已完成）
- 采购申请新增、编辑操作
- 审核功能（通过/退回）
- 入库确认功能
- 搜索和筛选功能

**优先级**：P0

#### 3.3.3 退货信息

**功能描述**：管理农资退货流程，记录退货原因和退款状态。

**用户故事**：

- US-3.3.3-1：作为基地管理者，我要对不合格农资发起退货，以便减少损失

**验收标准**：

- Given 用户选择已入库农资发起退货，When 填写退货原因和数量，Then 库存自动扣减，退货记录生成
- Given 退货完成，When 确认退款到账，Then 退货记录状态更新为"已退款"，财务数据同步

**优先级**：P0

#### 3.3.4 使用记录

**功能描述**：记录和审核农资使用情况，关联地块和农事任务。

**用户故事**：

### 3.8 模型预测中心

为提升果园管理的科学性与前瞻性，系统集成六大农业分析模型，基于历史数据与实时数据进行运算，输出预测、预警及农事建议。

#### 3.8.1 生长模型

**功能描述**：基于品种、积温、物候期、土壤水肥等数据，实时判断地块当前生长阶段，并推荐相应农事操作。

**用户故事**：
- US-3.8.1-1：作为基地管理者，我要查看各地块当前生长阶段，以便精准安排农事
- US-3.8.1-2：作为基地管理者，我要接收生长异常预警，以便及时采取措施

**验收标准**：
- Given 用户进入生长模型页面，When 查看，Then 显示生长阶段甘特图，展示所有地块当前所处生长阶段及进度
- Given 用户查看农事建议，When 系统推荐，Then 显示当前阶段建议农事（如"膨大期建议追施高钾肥"），支持一键生成农事计划任务
- Given 模型判断生长迟缓，When 与标准积温曲线偏差过大，Then 自动标红并推送至预警管理

**已实现功能**：
- 生长阶段甘特图展示
- 农事建议看板
- 生长异常报警

**数据表达**：折线图（实际积温 vs 理论积温）、雷达图（生长指标综合评分）

**优先级**：P1

#### 3.8.2 气象模型

**功能描述**：接入本地气象站数据和区域气象预报，提供精细化天气预测和苹果专属气象指数。

**用户故事**：
- US-3.8.2-1：作为基地管理者，我要查看未来7天精细天气预报，以便安排农事活动

**验收标准**：
- Given 用户进入气象模型页面，When 查看，Then 显示未来7天逐小时温度、降水、风速、湿度曲线
- Given 用户查看历史对比，When 选择时间范围，Then 显示今年与过去5年同期均温、降雨量对比柱状图
- Given 预报极端天气，When 检测到霜冻风险，Then 显示"距霜冻发生还有X小时"倒计时，并关联预警管理自动触发

**已实现功能**：
- 精细化天气预报展示
- 历史气象对比分析
- 极端天气倒计时预警
- 苹果专属气象指数（如"开花冻害风险指数"）

**数据表达**：温度曲线图、风险仪表盘

**优先级**：P1

#### 3.8.3 病虫害模型

**功能描述**：基于气象因子、虫情灯数据和历史发病数据，预测病虫害爆发风险，并提供防治建议。

**用户故事**：
- US-3.8.3-1：作为基地管理者，我要查看病虫害风险分布，以便精准防治
- US-3.8.3-2：作为植保员，我要获取病虫害防治建议，以便制定防治方案

**验收标准**：
- Given 用户进入病虫害模型页面，When 查看地图，Then 在地块GIS地图上叠加热力图层，红/黄/绿表示高/中/低发病风险
- Given 用户选择某病害，When 查看详情，Then 显示触发风险的因子（如"近5天湿度>80%且温度15-25℃"），并给出防治建议（用药配方、最佳喷药窗口）
- Given 用户查看历史记录，When 对比预测与实际，Then 显示模型预测准确率统计

**已实现功能**：

- 防治建议卡片

- Given 物候期发生偏差，When 系统检测，Then 显示提醒（如"今年盛花期预计较往年推迟5天"）
- Given 当前物候期到来，When 系统检测，Then 自动生成标准化农事模板，管理者可一键发布任务

## 十. 农业模型集成与应用

为提升果园管理的科学性与前瞻性，系统需集成六大农业分析模型。模型基于历史数据（农事记录、环境数据、产量记录）与实时数据（气象、土壤、虫情）进行运算，输出预测、预警及农事建议。

### 10.1 模型总览与职责

| 模型名称         | 核心输入                      | 核心输出                           | 主要用户        |
| :----------- | :------------------------ | :----------------------------- | :---------- |
| **生长模型**     | 品种、积温、物候期、土壤水肥            | 当前生长阶段（萌芽/开花/坐果/膨大/成熟）、阶段农事建议  | 基地管理者、地块负责者 |
| **气象模型**     | 本地气象站数据、区域气象预报            | 未来72小时精细天气预报、霜冻/大风/暴雨概率        | 企业管理者、基地管理者 |
| **病虫害模型**    | 气象因子（温湿度、降雨）、虫情灯数据、历史发病数据 | 特定病害（白粉病、锈病等）和虫害（蚜虫、红蜘蛛）爆发风险等级 | 基地管理者、植保员   |
| **物候期模型**    | 历年观测记录、积温、品种特性            | 当前物候期与常年对比（提前/推迟）、关键农时窗口       | 企业管理者、基地管理者 |
| **产量预估模型**   | 坐果率、果径抽样、历史单产、气象胁迫        | 分地块/分品种的预估总产、置信区间              | 企业管理者、销售部门  |
| **市场价格预测模型** | 历史市场价格、供需数据、季节性因子、期货指数    | 未来1-6个月苹果价格趋势、最佳销售窗口建议         | 企业管理者       |

### 10.2 PC端功能增强

在电脑端导航菜单中新增一级菜单 **“模型预测中心”** ，下设六个子模块（对应六个模型），同时原有预警管理、农事管理页面需展示模型生成的预警与建议。

#### 10.2.1 生长模型

- **页面内容**：
  - **生长阶段甘特图**：展示所有地块当前所处的生长阶段（如“膨大期”），并用进度条表示阶段已过百分比。
  - **农事建议看板**：根据模型推荐近期应做农事（例如“膨大期建议追施高钾肥”），支持一键生成农事计划任务。
  - **生长异常报警**：如模型判断生长迟缓（与标准积温曲线偏差过大），自动标红并推送至预警管理。
- **数据表达**：折线图（实际积温 vs 理论积温）、雷达图（生长指标综合评分）。

#### 10.2.2 气象模型

- **页面内容**：
  - **精细化天气预报**：展示未来7天逐小时温度、降水、风速、湿度曲线，以及苹果专属气象指数（如“开花冻害风险指数”）。
  - **历史气象对比**：今年与过去5年同期均温、降雨量对比柱状图。
  - **极端天气倒计时**：如预报霜冻，显示“距霜冻发生还有X小时”，并关联预警管理自动触发。
- **数据表达**：温度曲线图、风险仪表盘。

#### 10.2.3 病虫害模型

- **页面内容**：
  - **病虫害风险地图**：在地块GIS地图上叠加热力图层，红/黄/绿表示高/中/低发病风险。
  - **模型推演详情**：选择某病害（如苹果锈病），系统展示触发风险的因子（如“近5天湿度>80%且温度15-25℃”），并给出防治建议（用药配方、最佳喷药窗口）。
  - **历史准确率统计**：模型预测 vs 实际发生情况对比表，用于持续优化模型。
- **数据表达**：热力图、风险趋势折线图、防治建议卡片。

#### 10.2.4 物候期模型

- **页面内容**：
  - **物候期日历**：以年视图展示各品种（富士/嘎啦）的历年物候期（萌芽期、盛花期、成熟期）对比，并用虚线标注今年预测日期。
  - **农时偏差提醒**：例如“今年盛花期预计较往年推迟5天，建议延迟疏花计划”。
  - **物候期驱动任务**：根据当前物候期自动生成标准化农事模板（如“盛花期后7天：第一次疏果”），管理者可一键发布任务至地块负责者。
- **数据表达**：时间轴甘特图、偏差箭头标注。

#### 10.2.5 产量预估模型

- **页面内容**：
  - **产量预估仪表盘**：展示全公司总预估产量（吨）、各基地预估产量、各品种预估产量，并与上年实际产量对比。
  - **置信区间与风险因素**：显示预估误差范围（如 ±8%），并列出影响产量的主要正向/负向因子（如“坐果期遭遇干旱，造成减产5%”）。
  - **地块级预估下钻**：点击某地块，展示该地块估产依据（抽样果径分布图、坐果数统计）。
- **数据表达**：仪表盘、堆叠柱状图、KPI卡片。

#### 10.2.6 市场价格预测模型

- **页面内容**：
  - **价格走势预测图**：未来6个月苹果（分规格/分品种）预测价格曲线，同时标注历史同期价格作为参考。
  - **最佳销售时机建议**：模型输出“建议在X月前完成XX%的库存销售，预期收益率最高”。
  - **情景模拟**：管理者可调整输入参数（如“若延迟采收2周”），模型动态计算价格变动。
- **数据表达**：双轴折线图（预测价+历史价）、建议卡片。

### 10.3 移动端功能增强

移动端以“便捷提醒”和“即时决策”为核心，不在移动端做复杂模型配置，但需将模型输出转化为可操作的任务和直观查询。

#### 10.3.1 首页增强

- **模型快讯卡片**：在消息区域上方增加滚动栏，显示：
  - 生长模型：“当前95%地块进入膨大期，请关注水肥。”
  - 病虫害模型：“明日锈病风险中（指数65），建议喷施XX药剂。”
  - 市场价格模型：“预测下月价格上升3%，请留意销售。”
- **风险摘要**：用红/黄/绿灯展示整体健康度（综合生长、病虫害、气象风险）。

#### 10.3.2 服务 → 新增“模型预测”入口（或融入现有功能）

- **子功能列表**：

  - **气象早知道**：今日及未来3天天气卡片，附带苹果专属提醒（如“注意大风，避免打药”）。
  - **病虫害风险**：列表展示各地块高/中/低风险，点击可查看防治建议。
  - **产量估测**：简单展示全园预估产量，以及用户负责地块的预估产量。
  - **价格预测**：展示近期价格走势简图及销售建议。

#### 10.3.3 消息推送增强

## 十一、VR基地全景展示模块

### 11.1 功能概述

VR基地全景展示模块为苹果种植企业提供沉浸式的园区全景浏览体验，核心价值在于：
- 🔮 **沉浸式体验**：通过VR/360°全景技术，让管理者、客户、投资者身临其境地了解果园全貌
- 🏠 **远程参观**：无需实地到访，即可查看基地实景、地块分布、设备布局
- 🎯 **营销赋能**：为企业品牌展示、消费者认养、招商引资提供可视化支撑

### 11.2 功能需求

#### 11.2.1 全景数据管理
- **全景采集上传**：支持批量导入和单张上传全景图片（equirectangular格式）
- **全景场景管理**：管理多个全景场景，支持场景分组和切换

#### 11.2.2 全景展示浏览
- **全景主视图**：展示360°全景影像，支持鼠标/手势控制视角
- **热点标记与信息展示**：在全景中标记关键位置（地块、设备、建筑），点击显示详细信息
- **场景切换**：支持不同全景场景之间的跳转，模拟园区漫游

#### 11.2.3 数据联动
- **地块信息联动**：全景热点与地块信息关联，展示地块实时数据
- **设备状态联动**：全景热点与设备信息关联，展示设备实时状态
- **农事进度联动**：全景中展示当前农事执行进度

#### 11.2.4 多端适配
- **大屏端展示**：适配数据大屏，提供沉浸式展示体验，无人操作时自动播放预设漫游路径
- **PC端浏览**：适配桌面浏览器，支持精细操作

## 十二、无人机巡园模块

### 12.1 功能概述

无人机巡园模块作为人工巡园的补充手段，核心解决三大痛点：**人工巡园效率低、覆盖范围有限、数据采集不全面**。

通过"**高空视角+智能识别**"实现：PC端路径规划 → 无人机自动执行 → 移动端实时监控 → 大屏端数据分析。

### 12.2 功能需求 — PC端

#### 12.2.1 路径规划
- 在地图上规划无人机巡园路线，支持手动绘制和自动生成
- 设置航线高度（50-150米）、速度（5-15m/s）、拍照间隔（1-10秒）等参数
- 自动生成网格化覆盖路径，预览预计飞行时间、覆盖面积、预计照片数量

#### 12.2.2 任务管理
- 创建、调度和管理无人机巡园任务
- 支持立即执行或定时执行
- 查看任务执行状态和历史记录

#### 12.2.3 实时监控
- 实时查看无人机飞行状态和画面（延迟≤2秒）
- 显示无人机位置、高度、速度、电池电量、信号强度
- 低电量自动预警并提示返航

#### 12.2.4 AI识别管理
- 配置AI识别模型参数和识别规则
- 查看和审核AI识别结果（病虫害、异常情况自动检测）
- 支持批量处理识别结果

### 12.3 功能需求 — 移动端

- **实时监控**：查看无人机飞行状态和位置
- **异常处理**：接收并处理无人机发现的异常通知
- **巡园报告**：查看巡园报告摘要和历史记录

### 12.4 功能需求 — 大屏端

- **无人机巡园总览**：展示实时飞行任务状态、无人机位置、今日巡园统计
- **数据分析看板**：巡园覆盖率趋势图、病虫害热点区域热力图、无人机vs人工巡园对比

### 12.5 非功能需求

| 指标          | 目标值           |
| ----------- | ------------- |
| 实时视频延迟    | ≤2秒          |
| 图像识别响应时间  | ≤5秒/张        |
| 数据同步延迟    | ≤30秒         |
| 识别准确率      | ≥90%          |

## 十三、区块链溯源增强版模块

### 13.1 功能概述

区块链溯源增强版模块通过区块链技术实现苹果产品追溯数据的不可篡改存储，提升消费者信任度和品牌价值。

### 13.2 功能需求 — PC端

#### 13.2.1 追溯码生成
- 为每批次苹果生成唯一追溯码，并关联区块链存证
- 自动关联地块、品种、采收信息
- 生成二维码图片，支持导出/打印标签

#### 13.2.2 区块链存证管理
- 管理追溯数据的区块链存证状态
- 支持手动触发上链和状态查询
- 显示上链记录和交易哈希

#### 13.2.3 溯源数据编辑
- 编辑追溯码关联的产品信息、生产档案、基地信息
- 数据更新自动同步上链
- 支持查看变更历史

#### 13.2.4 追溯查询
- 查询追溯码详情，追踪产品全链路信息
- 按批次/地块统计追溯码生成情况
- 支持数据导出（Excel/PDF）

### 13.3 功能需求 — H5端（消费者扫码查询）

#### 13.3.1 产品信息展示
- 展示品种、规格、等级、采收日期、包装日期等

#### 13.3.2 生产档案展示
- 时间线展示关键农事节点（施肥、浇水、病虫害防治、套袋、采摘）
- 显示操作时间、操作人员、使用农资名称及用量

#### 13.3.3 基地信息展示
- 展示基地名称、位置、规模、成立时间、种植品种
- 显示认证资质（有机认证、绿色食品等）
- 展示基地实景照片

#### 13.3.4 基地实时环境展示
- 实时展示温度、湿度、光照强度、降雨量、风力
- 支持查看环境指标历史趋势

#### 13.3.5 企业展示
- 展示企业名称、简介、品牌故事、联系方式
- 支持拨打电话和分享功能

### 13.4 非功能需求

| 指标 | 目标值 |
| ---- | ------ |
| H5页面加载时间 | ≤3秒（4G网络） |
| 扫码响应时间 | ≤2秒 |
| 并发查询量 | ≥1000次/分钟 |
| 区块链存证响应时间 | ≤10秒 |
