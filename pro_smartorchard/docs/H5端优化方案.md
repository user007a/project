## 二、组件优化规范

### 2.1 顶部导航栏
```html
<header class="header">
  <button class="header-btn" aria-label="返回">
    <svg><!-- 返回图标 --></svg>
  </button>
  <div class="header-title">页面标题</div>
  <button class="header-btn" aria-label="操作">
    <svg><!-- 操作图标 --></svg>
  </button>
</header>
```

**样式要求：**
- 高度：52px
- 背景：渐变绿色 `linear-gradient(135deg, #16a34a, #15803d)`
- 固定顶部：`position: sticky; top: 0; z-index: 100;`
- 阴影：`box-shadow: 0 2px 12px rgba(0,0,0,0.1);`

### 2.2 底部导航栏
```html
<nav class="footer-nav">
  <div class="nav-item active">
    <svg class="nav-icon"><!-- 图标 --></svg>
    <span class="nav-text">首页</span>
  </div>
  <!-- 更多导航项 -->
</nav>
```

**样式要求：**
- 高度：56px + `env(safe-area-inset-bottom)`
- 背景：白色
- 阴影：`box-shadow: 0 -2px 20px rgba(0,0,0,0.08);`
- 激活状态：顶部3px指示器 + 绿色图标/文字

### 2.3 商品卡片
```html
<div class="product-card">
  <div class="product-img">
    <span class="product-badge">标签</span>
  </div>
  <div class="product-info">
    <div class="product-name">商品名称</div>
    <div class="product-desc">商品描述</div>
    <div class="product-price-row">
      <span class="product-price">¥68</span>
      <span class="product-price-original">¥88</span>
      <button class="product-cart-btn"><!-- 购物车图标 --></button>
    </div>
  </div>
</div>
```

**样式要求：**
- 圆角：16px
- 阴影：`0 2px 12px rgba(0,0,0,0.06)`
- 图片比例：1:1 或 4:3
- 按压反馈：`transform: scale(0.98);`

### 2.4 按钮规范
```css

  background: linear-gradient(135deg, var(--primary-500), var(--primary-600));

  background: var(--bg-secondary);
  color: var(--text-primary);
  border-radius: var(--radius-md);
```

## 四、交互优化规范

### 4.1 微交互
```css
/* 按压反馈 */
:active { transform: scale(0.95); }

/* 过渡动画 */
transition: all 0.2s ease;

/* 渐入动画 */
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}

/* 脉冲动画 */
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
```

### 4.2 Toast提示
```javascript
function showToast(message, duration = 2000) {
  const toast = document.createElement('div');
  toast.className = 'toast';
  toast.textContent = message;
  document.body.appendChild(toast);
  
  setTimeout(() => toast.classList.add('show'), 10);
  setTimeout(() => {
    toast.classList.remove('show');
    setTimeout(() => toast.remove(), 300);
  }, duration);
}
```

### 4.3 骨架屏加载
```css
.skeleton {
  background: linear-gradient(90deg, #f0f0f0 25%, #e0e0e0 50%, #f0f0f0 75%);
  background-size: 200% 100%;
  animation: shimmer 1.5s ease-in-out infinite;
}
```

## 五、响应式适配

### 5.1 断点规范
```css
/* 小屏手机 */
@media (max-width: 320px) {
  .product-grid { gap: 8px; }
  .product-img { height: 110px; }
}

/* 大屏手机 */
@media (min-width: 414px) {
  .product-grid { gap: 16px; }
}

/* 横屏 */
@media (orientation: landscape) {
  .header { padding-top: env(safe-area-inset-top); }
}
```

### 5.2 安全区域适配
```css
/* iOS安全区域 */
padding-bottom: env(safe-area-inset-bottom);
padding-top: env(safe-area-inset-top);
```
