## 五、单页优化标准流程

### 5.1 必做项（每个页面）

1. **添加CSS链接**
```html
<link rel="stylesheet" href="css/design-system.css">
```

2. **替换字体**
```css
/* 替换前 */
font-family: "Microsoft YaHei", "PingFang SC", sans-serif;

/* 替换后 */
font-family: var(--font-family);
```

3. **替换颜色变量**
```css
/* 替换前 */
background: #f0f2f5;
color: #333;

/* 替换后 */
background: var(--bg-base);
color: var(--text-primary);
```

4. **替换间距变量**
```css
/* 替换前 */
padding: 16px 20px;
margin: 0 20px;

/* 替换后 */
padding: var(--space-lg) var(--space-xl);
margin: 0 var(--space-xl);
```

5. **替换圆角变量**
```css
/* 替换前 */
border-radius: 8px;

/* 替换后 */
border-radius: var(--radius-lg);
```

6. **替换阴影变量**
```css
/* 替换前 */
box-shadow: 0 2px 8px rgba(0,0,0,0.2);

/* 替换后 */
box-shadow: var(--shadow-md);
```

7. **替换按钮样式**
```html
<!-- 替换前 -->
<button class="jg-btn">编辑</button>

<!-- 替换后 -->
<button class="jg-btn jg-btn-default">编辑</button>

<!-- 主按钮 -->
<button class="jg-btn jg-btn-primary">保存</button>
```

8. **替换Emoji为SVG**
```html
<!-- 替换前 -->
<span class="title-icon">📋</span>

<!-- 替换后 -->
<span class="title-icon">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
    <path d="M9 5H7a2 2 0 0 0-2 2v12a2 2 0 0 0 2 2h10a2 2 0 0 0 2-2V7a2 2 0 0 0-2-2h-2"/>
    <rect x="9" y="3" width="6" height="4" rx="1"/>
  </svg>
</span>
```

### 5.2 通用模板结构

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<style>
  * { margin: 0; padding: 0; box-sizing: border-box; }
  body {
    font-family: var(--font-family);
    background: var(--bg-base);
    color: var(--text-primary);
    font-size: var(--font-size-base);
    animation: pageIn var(--transition-slow) ease;
  }
  @keyframes pageIn { from { opacity: 0; transform: translateY(10px); } to { opacity: 1; transform: translateY(0); } }
  /* 页面特有样式 */
</style>
</head>
<body>
  <!-- 使用design-system中的组件类 -->
</body>
</html>
```

| 1 | CSS链接检查 | 确认`<link rel="stylesheet" href="css/design-system.css">`存在 |

## 八、注意事项

1. **保持向后兼容**：不破坏现有页面结构和功能
2. **渐进式优化**：每优化一个页面后验证正常显示
3. **性能优先**：避免添加过度动画和大型图片
4. **可维护性**：尽量复用design-system.css中的类
5. **无障碍**：保证文字对比度4.5:1以上
