# 数农智果 - 电脑端界面优化计划

## 一、项目概述

**项目名称：** 数农智果 - 智慧果园管理系统
**项目类型：** 农业数字化管理平台（B端企业级应用）
**目标用户：** 果园基地管理员、农技师、企业管理层
**优化范围：** `html/applefarm_backhand/` 目录下40+个电脑端页面

## 二、当前状态分析

### 2.1 已有的设计系统
- **design-system.css**：包含CSS变量（色彩、间距、圆角、阴影、动画）、按钮、统计卡片、面板、表格、表单、状态标签等基础组件
- **home.html**：系统首页，包含欢迎区、统计指标、监控面板、预警列表、待办任务、通知公告、模块入口
- **icons.js**：包含SVG图标定义

### 2.2 现有问题
| 维度 | 问题描述 |
|------|---------|
| **整体风格** | 偏功能性设计，缺乏现代感和品牌特色，视觉层次不够清晰 |
| **配色方案** | 绿色系为主，但渐变和对比度可以更丰富；缺少精致的配色体系 |
| **字体系统** | 统一使用13px，标题/正文/辅助文字缺乏层级区分 |
| **间距系统** | 组件内间距较一致，但组件间间距和留白不够讲究 |
| **卡片设计** | 统计卡片有渐变顶部条，但整体较朴素，hover效果单一 |
| **图标** | 使用SVG但风格不统一，缺少实景图标 |
| **图片** | 使用Unsplash图片但未做圆角、阴影等精致化处理 |
| **数据展示** | Mock数据较简单，缺乏真实感 |
| **内联样式** | home.html有大量内联样式，与design-system.css重复 |

## 三、目标设计系统

### 3.1 目标风格
**推荐风格：Soft UI Evolution + Bento Grid**
- 特点：柔和阴影、微妙深度、现代化企业感、有机形状
- 适合：企业级SaaS应用、现代农业科技产品
- 性能：优秀 | 无障碍：WCAG AA

## 七、验证步骤

| 步骤 | 验证内容 |
|------|---------|
| 1 | 设计系统CSS变量一致性检查 |
| 2 | 页面加载无样式闪烁（FOUC） |

## 八、注意事项

1. **保持向后兼容**：不破坏现有页面结构和功能
2. **渐进式优化**：每次优化后验证页面正常显示
3. **性能优先**：避免过度动画和大型图片
4. **可维护性**：尽量复用design-system.css中的类
5. **无障碍**：保证文字对比度4.5:1以上，焦点状态可见
