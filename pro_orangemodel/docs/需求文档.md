# 南丰蜜桔模型管理系统需求文档

> 本文档基于已实现的HTML原型（`html/` 目录下52个页面）整理编写，所有功能描述均以实际原型实现为准。

## 1. 项目概述

### 1.1 项目背景

南丰蜜桔是南丰县特色优势农业产业，是助力地方乡村振兴、农业增效、农户增收的核心支柱产业。当前南丰蜜桔种植产业仍存在传统种植模式粗放、生长环境管控不精准、农事管理缺乏科学依据、病虫害防控滞后、气象灾害抵御能力弱、数字化应用工具不足等痛点问题，导致蜜桔品质参差不齐、产量稳定性不足、病虫害及气象灾害损失难以有效规避，制约了南丰蜜桔产业标准化、智能化、高品质化发展。

为破解产业发展瓶颈，基于现有的南丰蜜桔全产业链大数据平台的数据基底和相关业务应用，依托现有果园物联网监测设备、气象监测系统基础硬件资源，结合人工智能、物联网、大数据等现代信息技术，本项目聚焦南丰蜜桔种植端核心需求，面向涉农企业、果园、种植合作社、种植大户等涉农主体，由农业农村局牵头建设南丰蜜桔生长模型和病虫害防控模型智能化系统。

### 1.2 建设目标

本项目以提质、稳产、防灾、增效为核心建设目标，依托大数据分析、AI智能建模、物联网精准监测技术，搭建集数据采集、模型运算、智能分析、预警防控、农事指导、可视化展示、移动端服务于一体的南丰蜜桔智慧种植管理系统，具体建设目标如下：

1. **构建精准化南丰蜜桔生长模型**：整合土壤、气候、光照、温度、湿度等环境数据，结合蜜桔幼苗期、生长期、开花期、落果期、果实膨大期、成熟期全生长周期状态数据及农事管理数据，建立环境、管理、生长状态、产量品质的最优关联模型，实现种苗选育、施肥、灌溉、剪枝等农事操作的精准指导，精准管控蜜桔甜度、果形、大小、色泽等品质指标，全面提升蜜桔优品率。

2. **搭建专业化病虫害防控模型与数据库**：覆盖南丰蜜桔常见病害、虫害类型，建立标准化病虫害数据库，结合物联网实时监测数据、气象环境数据，实现病虫害提前预警、实时报警、智能研判、科学防治，全面提升果园病虫害防控能力。打通本地化气象监测设备与气象系统数据接口，实时捕捉气候环境变化，精准预判气象灾害风险，输出针对性防范措施，最大限度降低气象灾害对蜜桔种植的损失。

3. **提供个性化农事智能建议**：支持农户手动录入果园土壤养分、土壤墒情、温湿度等自定义数据，结合系统模型，提供可落地的农事操作建议。

4. **搭建政企双向服务体系**：面向农业农村局工作人员提供后台数字化管理能力，实现模型、数据、预警、用户、规则的一体化管控；面向种植端涉农主体提供轻量化微信小程序服务，实现便民化、常态化的种植服务赋能。

### 1.3 总体架构

根据产业大数据中心"一平台一系统"建设规范和整改要求，本系统作为南丰蜜桔产业链接大数据平台下属模型应用子系统，不重复建设基础数据底座与通用后台能力，依托现有产业大数据平台统一数据资源、统一权限体系、统一集成规范开展建设。

系统整体功能架构为三大核心模块：

| 模块 | 面向用户 | 核心功能 |
|------|---------|---------|
| 模型后台管理系统 | 农业农村局业务管理人员 | 模型参数配置、运算调度、规则维护、预警处置、农事策略管理、应用数据统计 |
| 微信小程序 | 涉农企业、果园、合作社、种植大户 | 环境监测、设备管理、数据上报、AI病虫害智能识别、病虫害知识库、预警上报、AI农事助手、市场信息、农技资讯 |
| 模型成效展示中心 | 农技监管、产业研判、成果展示 | 生长模型监测大屏、病虫害与气象灾害预警大屏 |

所有模型运算、农事服务、预警展示、产业应用数据均向上汇聚至产业大数据平台，实现全域数据共享、业务联动、统一管控。

### 1.4 建设周期

本项目整体建设周期为90个工作日，自项目合同签订后次日起计算。

## 5. 算法需求

### 5.1 南丰蜜桔生长模型算法（5项）

| 算法名称 | 算法描述 | 应用场景 |
|---------|---------|---------|
| 有效积温物候识别算法 | 依据各生育阶段有效积温阈值，结合时序气温数据，自动判定物候期，切换模型参数集 | 模型调度基础，物候预判 |
| LightGBM梯度提升回归模型 | 以气象、土壤、农事操作为输入特征，拟合新梢生长、果径增长、糖分积累趋势 | 品质指标预测 |
| 时序异常检测算法（3σ准则+移动平均融合） | 构建正常生长区间基线，识别生长胁迫状态，自动生成长势异常预警 | 实时预警监测 |
| 多约束农事优化推荐算法（专家规则引擎+启发式寻优） | 以品质目标为优化目标，结合物候期、土壤条件、气象预报约束，搜索最优农事方案 | 农事智能推荐 |
| FAO彭曼-蒙特斯作物水分平衡模拟算法 | 估算植株蒸腾量，计算水分盈亏，确定最佳灌溉时机与灌水量 | 精准灌溉推荐 |

### 5.2 病虫害防控模型算法（6项）

| 算法名称 | 算法描述 | 应用场景 |
|---------|---------|---------|
| 病虫害风险分级逻辑回归预测模型 | 输入温湿度、降雨、物候阶段、历史发病记录，预测病虫害爆发概率 | 区域病虫害预警 |
| MobileNetV2轻量化图像分类CNN模型 | 对叶片、果实、虫体图像进行特征提取，完成病虫害种类识别 | 移动端AI识别 |
| 时空克里金空间插值算法 | 基于离散点位数据，生成连续空间风险分布，输出风险热力图 | 风险可视化 |
| 气象灾害阈值判定算法 | 比对气象数据与预设阈值，识别灾害风险等级，推送防护措施 | 气象灾害预警 |
| 正向链式预警规则推理引擎算法 | 整合模型预测、人工上报、气象条件、物候阶段，综合判定预警 | 预警综合判定 |
| 病虫害时序传播趋势预测算法（ARIMA时序模型） | 基于历史发生序列，推演未来7-15天扩散趋势 | 中长期趋势预判 |

### 5.3 气象灾害模型算法（5项）

| 算法名称 | 算法描述 | 应用场景 |
|---------|---------|---------|
| 极端温度识别算法 | 基于历史温度序列和阈值判定，识别极端高温/低温事件 | 温度灾害预警 |
| XGBoost灾害分类算法 | 以多源气象特征为输入，分类预测灾害类型及概率 | 灾害类型识别 |

| 灾害风险评估算法 | 综合灾害强度、影响范围、承灾体脆弱性，评估风险等级 | 风险量化评估 |
| LSTM时序预测算法 | 基于长序列气象数据，预测未来气象要素变化趋势 | 中长期气象预测 |

## 6. 系统集成需求

### 6.1 平台底座资源复用集成

系统全面复用现有产业大数据平台的以下能力：

| 能力类型 | 复用内容 |
|---------|---------|
| 数据汇聚 | 物联网设备数据汇聚、气象系统对接 |
| 数据处理 | 数据清洗标准化能力 |
| 基础设施 | 政务网络资源、数据存储备份 |
| 权限体系 | 统一用户认证与权限管理 |

### 6.2 双向数据共享与联动集成

建立子系统与上级产业大数据平台双向数据共享机制：

- **下行数据**：从大数据平台统一获取标准化果园环境数据、气象数据、设备状态数据、基础用户数据
- **上行数据**：本系统将模型运算结果、品质预测数据、病虫害预警数据、农事服务记录、用户录入数据、大屏统计应用数据、预警处置台账等业务数据，实时同步汇聚至产业大数据平台

### 6.3 内部应用模块集成

本系统三大核心模块深度闭环联动：

```
模型后台管理系统（运算、配置、管理）
        ↓
模型数据展示中心（可视化统计、预警态势）
        ↓
微信小程序（农事建议、风险提示、气象服务）
        ↓
用户反馈数据回流 → 模型优化
```

### 6.4 业务能力集成

依托大数据平台基础能力，叠加本项目蜜桔专属AI模型能力、病虫害专项防控能力、种植全周期农事智能指导能力，形成通用底座+行业专项应用的集约建设模式。
