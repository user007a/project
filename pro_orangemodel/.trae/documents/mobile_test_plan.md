## 三、测试步骤

### 3.1 自动化测试（浏览器工具）
1. 使用浏览器打开首页 `mb_home.html`
2. 依次访问所有页面，记录加载状态
3. 模拟不同设备尺寸，检查响应式适配

### 3.2 手动功能测试
1. 逐一测试每个页面的所有功能按钮
2. 测试导航跳转路径
3. 测试表单输入和提交
4. 测试弹窗打开和关闭

### 3.3 视觉检查
1. 检查颜色、字体、间距一致性
2. 检查图标显示质量
3. 检查图片加载状态
4. 检查布局是否整齐

---

## 四、测试报告输出

测试完成后，输出以下内容：
- 页面加载状态汇总
- 功能测试结果（通过/失败/待确认）
- UI一致性检查结果

- Bug列表及严重程度
- 改进建议

## 五、风险与注意事项

1. **图片加载**：文生图API可能不稳定，需检查SVG fallback是否生效
2. **数据模拟**：所有数据为mock数据，需确认数据格式正确
3. **浏览器兼容性**：重点测试Chrome和Safari移动端模式
4. **网络环境**：测试时确保网络稳定，避免因网络问题导致加载失败
