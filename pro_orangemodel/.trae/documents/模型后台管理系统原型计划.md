# 模型后台管理系统HTML原型执行计划

## 1. 需求分析

根据《需求说明书.md》第2.1节，模型后台管理系统面向农业农村局业务管理人员，包含以下7个核心模块：

| 模块 | 二级菜单数量 | 功能描述 |
|------|-------------|---------|
| 系统首页 | 1个页面 | 登录信息、统计数据、农事历、气象提醒、快捷入口 |
| 模型管理 | 5个页面 | 生长模型、病虫害防控模型、病害数据库、虫害数据库、灾害数据库 |
| 数据管理 | 5个页面 | 人工采集、数据对接、外部抓取、共享数据、数据表管理 |
| 规则管理 | 4个页面 | 预警规则、内容设置、流程设置、发送模板 |
| 预警管理 | 5个页面 | 预警管理、处置记录、识别日志、风险提示、预测提示 |
| 运行监控 | 5个页面 | 长势研判、品质预测、农事推荐、病虫害趋势研判、模型日志 |
| 系统管理 | 4个页面 | 用户管理、系统日志、数据同步、小程序设置 |

**总计：1个主框架 + 29个功能页面**

## 2. 技术方案

### 2.1 设计风格
- **布局**：左侧深色侧边栏导航 + 顶部Tab标签栏 + iframe内容区域
- **风格**：现代企业级后台管理系统风格
- **配色**：主色调采用农业主题绿色系，搭配白色背景和灰色辅助色

### 2.2 技术栈
- **HTML5**：页面结构
- **Tailwind CSS 3**：样式框架（通过CDN引入）
- **Iconify**：图标库（通过CDN引入）
- **原生JavaScript**：交互逻辑（侧边栏展开/收起、Tab管理、菜单导航）

## 3. 执行步骤

### 步骤1：创建目录结构
- 创建 `html/backhand/` 主目录
- 创建6个子目录：`model/`, `data/`, `rule/`, `alert/`, `monitor/`, `system/`

### 步骤2：生成主页面 index.html
- 左侧侧边栏：包含7个一级菜单及所有二级菜单
- 顶部导航栏：系统标题、用户信息、Tab标签栏
- 主内容区：iframe框架，默认加载 home.html
- 交互功能：
  - 侧边栏展开/收起
  - Tab标签切换
  - 点击菜单在新Tab中打开页面

### 步骤3：生成系统首页 home.html
- 用户信息展示区域
- 统计卡片：模型数量、用户数量、预警数量、活跃用户数量
- 南丰蜜桔农事历
- 气象/灾害提醒
- 快捷入口按钮

### 步骤4：生成模型管理模块（5个页面）
- `growth_model.html`：生长模型运行状态、训练数据、模型参数、农事年历
- `pest_model.html`：病虫害防控模型运行状态、训练数据、模型参数
- `disease_db.html`：病害数据库表格（名称、症状、高发期、防治方案）
- `insect_db.html`：虫害数据库表格（名称、症状、高发期、防治方案）
- `disaster_db.html`：灾害数据库表格（类型、影响范围、损失情况）

### 步骤5：生成数据管理模块（5个页面）
- `manual_collect.html`：人工采集数据管理表格
- `data_connect.html`：物联网设备/气象系统数据对接管理
- `external_fetch.html`：外部数据源抓取配置
- `shared_data.html`：与产业大数据平台共享数据管理
- `table_manage.html`：数据表管理（17张数据表清单）

### 步骤6：生成规则管理模块（4个页面）
- `alert_rule.html`：预警规则配置表格（阈值设置）
- `content_setting.html`：预警消息发送对象范围设置
- `flow_setting.html`：预警消息审核流程配置
- `send_template.html`：预警消息发送内容模板管理

### 步骤7：生成预警管理模块（5个页面）
- `alert_manage.html`：预警信息列表（级别、来源、审核状态）
- `dispose_record.html`：预警处置记录跟踪
- `recognize_log.html`：病虫害AI识别日志
- `risk_hint.html`：气象灾害风险提示
- `predict_hint.html`：生长预测提示

### 步骤8：生成运行监控模块（5个页面）
- `growth_judge.html`：实时长势研判数据监控
- `quality_predict.html`：品质预测数据（甜度、果形、优品率）
- `farming_recommend.html`：农事推荐记录和落地情况
- `pest_trend.html`：病虫害爆发趋势研判
- `model_log.html`：模型运行日志（查询、导出）

### 步骤9：生成系统管理模块（4个页面）
- `user_manage.html`：工作人员和农户用户管理
- `system_log.html`：系统运行日志
- `data_sync.html`：与产业大数据平台数据同步状态
- `mini_program.html`：微信小程序配置设置

### 步骤10：验证测试
- 验证所有页面链接正确性
- 验证侧边栏菜单导航功能
- 验证Tab标签切换功能
- 验证侧边栏展开/收起交互

## 4. 设计决策

### 4.1 配色方案
- 主色调：`#22C55E`（绿色，象征农业、生机）
- 侧边栏背景：`#1E293B`（深蓝灰色，企业级风格）
- 主内容背景：`#F8FAFC`（浅灰色，舒适阅读）
- 强调色：`#3B82F6`（蓝色，用于按钮和链接）

### 4.2 图标选择
- 使用Iconify图标库
- 农业相关图标：`🍊`（蜜桔）、`🌱`（生长）、`🐛`（虫害）、`🌧️`（气象）
- 通用管理图标：`📊`（统计）、`⚙️`（设置）、`📋`（列表）、`🔔`（预警）

### 4.3 交互设计
- 侧边栏支持展开/收起，收起后仅显示图标
- 点击菜单自动在顶部添加Tab标签
- Tab标签支持关闭（保留首页）
- 页面切换带有平滑过渡动画

## 5. 风险应对

### 5.1 潜在风险
| 风险 | 影响 | 应对措施 |
|------|------|---------|
| 路径引用错误 | 页面无法正常加载 | 使用相对路径，验证所有链接 |
| 样式兼容性问题 | 页面显示异常 | 使用Tailwind CSS，确保兼容性 |
| Tab管理冲突 | 重复打开页面 | 检测已打开的Tab，避免重复 |
| 数据表格过长 | 页面滚动体验差 | 使用固定表头+分页设计 |

### 5.2 验证标准
- 所有页面可正常访问（无404错误）
- 侧边栏菜单与页面内容对应正确
- Tab标签切换流畅
- 页面在主流浏览器（Chrome、Firefox、Edge）中显示正常
