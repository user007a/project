# 模型数据展示中心 HTML 原型执行计划

## 1. 需求分析

### 1.1 业务背景
根据《需求说明书.md》第 2.3 节「模型数据展示中心」，本次可视化展示建设两个专属模型业务数据大屏，聚焦两大核心模型的预测预警、运行状态、落地应用成效。

### 1.2 大屏功能清单

#### 大屏一：南丰蜜桔生长模型监测大屏

| 展示维度 | 子维度 | 优先级 |
|---------|-------|--------|
| 全域生长概况 | 全县果园数量、种植面积、当前物候期分布、总体长势健康度 | 高 |
| 果园基础概况 | 种植主体类型分布、品种分布、树龄分布、地块规模分布 | 高 |
| 环境监测实时数据 | 土壤温度、土壤湿度、土壤养分、空气温度、空气湿度、光照强度 | 高 |
| 各生长阶段果园分布 | 幼苗期、生长期、开花期、落果期、膨大期、成熟期果园数量及占比 | 高 |
| 长势健康度分析 | 健康度分级统计、异常地块预警、长势趋势分析 | 高 |
| 品质预测数据 | 甜度预测、果形预测、优品率预测、品质提升趋势 | 高 |
| 智能农事建议落地统计 | 农事建议推送数量、采纳率、落地成效分析 | 中 |
| 长势异常预警 | 预警数量、预警类型分布、处置进度、预警趋势 | 中 |

#### 大屏二：蜜桔病虫害与气象灾害预警大屏

| 展示维度 | 子维度 | 优先级 |
|---------|-------|--------|
| 病虫害知识库统计 | 病害种类数量、虫害种类数量、高发病虫害排名 | 高 |
| 实时病虫害识别记录 | 识别任务数量、识别准确率、疑难样本分布 | 高 |
| 区域病虫害风险热力分布 | 风险等级热力图、高风险区域标记、扩散趋势预测 | 高 |
| 分级预警信息台账 | 预警总数、各级别预警数量、预警类型分布、预警处置状态 | 高 |
| 病虫害处置完成率 | 处置完成数量、处置完成率、处置效果评估、未处置预警提醒 | 高 |
| 气象实时数据 | 气温、湿度、降雨量、风速、未来7日气象趋势 | 高 |
| 气象灾害风险预判 | 灾害类型预警、风险等级、影响范围、防护建议 | 高 |
| 灾害防护建议落地情况 | 防护建议推送数量、采纳实施情况、防护效果评估 | 中 |
| 年度病虫害及灾害损失对比分析 | 年度病虫害发生趋势、灾害损失对比、防控成效评估 | 中 |
| 模型预警准确率统计 | 预警准确率、误报率、漏报率、准确率趋势分析 | 中 |

## 3. 实施步骤

### 步骤 1：创建生长模型监测大屏

**文件**: `html/dataanlye/growth_dashboard.html`

**内容规划**:
1. 页面头部：标题「南丰蜜桔生长模型监测大屏」
2. 筛选面板：区域、时间选择
3. KPI 网格（8个）：果园数量、种植面积、健康度、物候期、甜度预测、优品率、农事建议采纳率、预警数量
4. 左侧面板：
   - 环境监测实时数据（土壤温湿度、空气温湿度、光照强度）
   - 长势健康度分析（环形图 + 分级统计）
   - 长势异常预警列表
5. 中间核心区：果园分布地图/实景展示 + 生长阶段分布图例
6. 右侧面板：
   - 品质预测数据（折线图）
   - 智能农事建议落地统计（柱状图）
   - 各生长阶段果园分布（饼图）
7. 底部：生长趋势分析图表

### 步骤 2：创建病虫害与气象灾害预警大屏

**文件**: `html/dataanlye/pest_dashboard.html`

**内容规划**:
1. 页面头部：标题「蜜桔病虫害与气象灾害预警大屏」
2. 筛选面板：区域、时间选择
3. KPI 网格（8个）：病害种类、虫害种类、识别准确率、预警总数、处置完成率、灾害类型、防护建议采纳率、预警准确率
4. 左侧面板：
   - 病虫害知识库统计（病害/虫害数量）
   - 实时识别记录（任务列表）
   - 分级预警信息台账（表格）
5. 中间核心区：区域风险热力分布/地图
6. 右侧面板：
   - 气象实时数据（气温、湿度、降雨量、风速）
   - 气象灾害风险预判（灾害类型 + 等级）
   - 模型预警准确率统计（趋势图）
7. 底部：年度病虫害及灾害损失对比分析

### 步骤 3：数据模拟与交互

## 5. 风险与注意事项

| 风险项 | 描述 | 应对措施 |
|-------|------|---------|
| 数据模拟 | 原型需要使用模拟数据，可能与实际数据结构不符 | 预留数据接口位置，标注数据来源 |
| 地图展示 | 需求中提到风险热力图，原型阶段可能无法实现真实地图 | 使用示意图或 ECharts 地图组件模拟 |
| 大屏适配 | 需求要求适配 1920×1080 分辨率 | 使用响应式布局，设置合适的字体大小 |
| 图表数量 | 两个大屏包含较多图表，页面加载可能较慢 | 使用懒加载，优化图表渲染 |
