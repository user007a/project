# 题库数据格式转换计划

## 一、需求分析

### 1.1 现有文件分析

| 文件名称 | 用途 | 结构特点 |
|---------|------|---------|
| 试题批量导入模板.xlsx | 系统导入模板 | 包含说明行 + 表头行，列：试题分类、试题类型、试题难度、答案、分值、解析、选项1-8 |
| 养老护理五级题库.xlsx | 原始题库数据 | 共1028行，列：题型、题目、答案、解析、A、B、C、D、E、F、G、H |

### 1.2 字段映射关系

| 导入模板字段 | 题库数据字段 | 转换规则 |
|------------|------------|---------|
| 试题分类 | - | 默认填写"养老护理五级" |
| 试题类型 | 题型 | 直接映射 |
| 试题难度 | - | 默认填写"中等" |
| 答案 | 答案 | 多选题需转换为数字格式 |
| 分值 | - | 默认填写"5" |
| 解析 | 解析 | 直接映射 |
| 选项1-4 | A-D | 直接映射 |
| 选项5-8 | E-H | 直接映射 |
| 试题内容 | 题目 | 直接映射 |

### 1.3 答案格式转换规则

- **多选题**：答案转换为数字逗号分隔（如ABC→1,2,3）
- **判断题**：答案转换为1（正确）或0（错误）

## 二、实施步骤

1. 读取题库数据文件
2. 配置字段映射（分类、难度、分值）
3. 转换数据格式
4. 处理多选题和判断题答案格式
5. 生成输出文件

## 三、输出结果

输出文件：养老护理五级题库-导入.xlsx
