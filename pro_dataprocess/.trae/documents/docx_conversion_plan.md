# docx题库数据格式转换计划

## 一、需求分析

### 1.1 现有文件分析

| 文件名称 | 用途 | 结构特点 |
|---------|------|---------|
| 试题批量导入模板.xlsx | 系统导入模板 | 列：试题分类、试题类型、试题难度、试题内容、答案、分值、解析、选项1-8 |
| 老年人能力评估师三级题库.docx | 原始题库数据 | 共1422个段落，包含题目、选项、答案 |

### 1.2 docx数据格式分析

从文档内容分析，数据格式如下：
`
1、题目内容
A.选项A
B.选项B
C.选项C
D.选项D
正确答案：A
`

### 1.3 字段映射关系

| 导入模板字段 | docx数据来源 | 转换规则 |
|------------|------------|---------|
| 试题分类 | - | 默认填写"老年人能力评估师三级" |
| 试题类型 | - | 默认填写"单选题"（根据数据格式判断） |
| 试题难度 | - | 默认填写"中等" |
| 试题内容 | 题目行 | 提取题目编号后的内容 |
| 答案 | 正确答案行 | 提取字母（如A） |
| 分值 | - | 默认填写"5" |
| 解析 | - | 留空 |
| 选项1-4 | A-D选项行 | 提取选项内容 |

## 二、实施步骤

1. 读取docx文档内容
2. 解析题目结构（题目、选项、答案）
3. 构建DataFrame并映射字段
4. 生成符合导入模板格式的Excel文件

## 三、潜在风险与处理

| 风险类型 | 风险描述 | 处理方案 |
|---------|---------|---------|
| 格式不一致 | docx中可能存在不同格式的题目 | 检测并跳过异常格式 |
| 多选题识别 | 需识别是否有多选题目 | 根据答案格式判断（如"AB"表示多选） |
| 数据量较大 | 1422个段落需要解析 | 逐行解析并统计题目数量 |

## 四、输出结果

输出文件：老年人能力评估师三级题库-导入.xlsx
