# 江西省农业农村厅办公室关于切实做好第三次降雨集中期防范应对工作的通知

| 发布日期 | 2019-07-03 |
| 来源 | 江西省农业农村厅种植业管理处 |
| 原文链接 | https://nync.jiangxi.gov.cn/jxsnynct/fzjz/content/content_1877678449776361472.html |

## 正文

各市、县（区）农业农村局：

　　入汛以来，我省多地出现暴雨洪涝等自然灾害。据气象部门预计，7月4～7日我省将迎来第三次降雨集中期，其中，4日北部降雨明显，5～7日赣北赣中部分地区有暴雨，局部大暴雨；4日08时至8日08时，累计雨量赣北赣中60～130毫米，局部可达200毫米以上。为切实加强近期强降雨天气防范应对工作，确保完成全年农业发展目标任务，特别是全年粮食生产目标，现就有关工作通知如下。

　　一、切实抓好防灾减灾责任落实。6月6日以来，我省部分地区出现集中强降雨，农业生产遭受一定影响。各地要进一步提高政治站位，增强风险意识和责任意识。一是加强组织领导。压紧压实各级主体责任，切实做好灾情预警、减灾决策和抗灾指导。主要负责同志亲自研究部署、分管负责同志靠前指挥。二是加强部门协作。加强与应急管理、气象、水利等有关部门的联系会商，密切关注灾害性天气动态，加强雨情水情预测预判，及早发布预警信息，切实做好防范应对工作，形成农业防灾减灾工作强大合力。三是加强应急值守。严格执行24小时值班制度，做好领导带班和值班备勤，强化灾情调度，及时收集、核实和上报灾情，提高信息的时效性和准确性。

　　二、切实做好防灾减灾技术指导。各地要立足科学防灾减灾，制定完善配套技术措施。根据农情、灾情动态，及时组织农技人员进村入户，深入田间地头，点对点、面对面开展技术指导服务。充分利用广播电视、网络、江西微农、12316短信等媒介，提醒广大新型农业经营主体和农民群众早预防、早准备，确保灾情信息发布到位；加强对农民防灾减灾、灾后恢复农业生产的技术措施培训和指导，确保防灾技术措施落实到位。

　　三、切实加强灾害天气应急防范。各地要根据当地农作物种类和生育进程，以及畜牧、水产养殖的实际情况，分类制定有针对性的防灾减灾措施。及时组织力量清理农田沟渠和田间“三沟”，保证田间排水顺畅；及时抢收早稻和栽插双晚，做到成熟一块收获一块，收获一块栽插一块；加强在田作物肥水调控，尽快恢复正常长势；加强对水产亲本池、孵化池、育苗池的巡查；指导养殖户做好畜禽补栏，做好重大动物疫病和鱼类病害防控，确保灾后无大的疫情，确保农业生产稳定。
