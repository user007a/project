## 正文

一、冬后基数及发生预测根据各县（区）植保站（局）对二化螟冬后基数调查，全市最高每亩105300条，加权平均每亩9341条，比去年增加36.1%，远高于大发生标准。根据各地二化螟冬后基数、发育进度调查以及气候条件和栽培管理等情况分析，预计全市一代二化螟偏重发生，局部重发生，重于去年。二、一代二化螟发生预期根据各县（区）对二化螟发育进度及灯下蛾量判定，今年一代二化螟发育进度比去年早2—7天。灯下见虫比去年早2-3天。因二化螟越冬场所不同，发育进度差异较大，预计一代二化螟发蛾期较长，有多个高峰。附：部分县（区）一代二化螟羽化、孵化高峰期：

 | 羽化高峰期 | | 4月22—27日 | | 4月19—25日 | | 4月18—25日 | | 4月19日-25日 | 

 | 孵化高峰期 | | 5月4—8日 | | 4月29—5月5日 | | 4月28—5月4日 | | 4月27—5月3日 | 
三、防治意见各级植保部门要加强田间监测调查，根据本地二化螟卵孵化情况，适时指导农户做好一代二化螟防治工作。1、防治对象：早稻田、春制种田、早播中稻秧田及一晚秧田。枯鞘丛率达8%以上的田块须用药防治。2、防治适期：根据移栽、抛秧及直播时间的早晚，第一次用药时间为5月上旬，第二次用药时间为5月中旬，两次间隔时间约7天。3、防治用药：亩用16000IU/毫克苏云金杆菌可湿性粉剂300—400克或20%氯虫苯甲酰胺10—15毫升或5%甲氨基阿维菌素苯甲酸盐水分散粒剂25—40克或40%三唑磷乳油 100—150毫升，打药期间田间保持寸水层。
