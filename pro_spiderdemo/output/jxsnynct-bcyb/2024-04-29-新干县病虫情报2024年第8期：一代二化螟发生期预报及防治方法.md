## 正文

—、发生量、发生期：据各乡镇监测点调查,3月26日剥查二化螟冬后残留基数亩虫量,最高56000条(去年60200条),平均30800条(去年32958条)。结合历年资料分析、近期气象条件和田间发生以及测报灯下蛾量发生实况,预计一代二化螟偏重发生，局部重发。发生期如下：发蛾始盛期4月8日-12日，发蛾高峰期4月14日-22日；孵化始盛期4月20日-24日，孵化高峰期4月26日-5月4日。二、当前虫情： 虫情测报灯下3月29日（去年4月1日）见蛾4只,4月14日（去年4月20日）始见高峰,有虫60只，4月22日有虫15只。三、防治意见：今年二化螟冬后基数高,望农户加强田间检查,当亩枯鞘丛率超过8%时应立即用药防治。㈠防治对象：水稻二化螟、稻水象甲、负泥虫、叶稻瘟㈡防治时间：　⑴4月13日前移(抛)栽的早稻田及早播直播田,应在5月3～9日要打好一次药，5月10-15日打第二次药。⑵4 月13日以后移(抛)栽的早稻田,应在5月8～14日打好一次药，5月15-20日打好第二次药。⑶对那些防治不力的田块要在5月25日左右挑治好枯心团。四、防治方法：㈠防治二化螟药剂（可选用以下一种或两种混合药剂兑水60斤喷雾进行防治）① 16000IU/毫克苏云金杆菌可湿性粉剂； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ②5%阿维菌素;② 5%甲维盐； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;④90%杀虫单;㈡防治稻水象甲药剂：可选用40%三唑磷或20%氯虫苯甲酰胺喷雾㈢防治稻瘟病药剂（可选用以下一种药剂兑水60斤喷雾进行防治）①1000亿芽孢/克枯草芽孢杆菌；②6%春雷霉素可湿性粉剂；③75%三环唑认真搞好大田化学除草㈠大田抛移栽后化学除草⒈施用时间：抛移栽后5～7天(秧苗越嫩越推后用)，施药后保持1寸深的水层，水层在水稻心叶以下。⒉施用方法：⑴抛栽田亩可选用以下一种除草剂拌适量尿素于栽后5天左右均匀撒施。①25%苄·丁； &nbsp; &nbsp;②46%苄嘧·苯噻酰 ；　　③35%丁·苄⑵移栽田亩可选用以下一种除草剂拌适量尿素于栽后7天左右均匀撒施。① 22%苄·乙； &nbsp;②26%苄·异丙甲；③20%苄·乙可湿性粉剂㈡直播田亩选用以下一种除草剂于播后2～4天兑水30～50公斤均匀喷雾。(施药时田板保持湿润，沟中有浅水层)①300克/升丙草胺+10%苄嘧磺隆；②20%苄嘧磺隆.丙草胺㈢针对往年有千金子的稻田，抛栽或直播后，千金子长至2叶1心～4叶，用40%氰氟草酯；(施药时田板保持湿润，沟中有浅水层，24小时后复水2～3厘米水层。)※ &nbsp;《农作物病虫害防治条例》自2020年5月1日起正式实施 &nbsp;贯彻《农作物病虫害防治条例》、保障农作物增产增收※ &nbsp;新修订《农药管理条例》自2017年6月1日起正式实施 全面贯彻《农药管理条例》、切实保障农产品质量安全※ &nbsp;农药肥料包装废弃物回收处置工作建立“政府主导，市场运作，公众参与，网点回收，专业处置”的回收处置工作机制，以“使用者交回、经营者回收、归集点贮存、专业化处置”为基本模式。※ &nbsp;深入推进农药科学安全使用，持续推进农业高质量发展和化学农药减量化。
