## 正文

一、二代二化螟发生实况今年二代二化螟中等发生，在早稻田上造成枯心（枯穗）率一般在0．2－0．4％，高的达4．3％以上，在中稻田上枯鞘株率一般为1－3％，高的为7％以上，枯心率一般为0．4－1．2％，高的达4％以上，在早栽晚稻田枯鞘株率一般为0－0．8％。田间亩残存虫量平均4860条，最高10840条，略低于去年。二、三代二化螟发生预测综合分析我县中、晚稻苗情、品种布局、栽培管理、气象预报等因素，预测2026年我县三代二化螟中等发生，发生程度相似于去年。预测二代二化螟发育进度如下：
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 7月21－26日 | | 7月28－8月3日 | | 8月16－21日 | 

 | 羽化 | | 7月26－31日 | | 8月3－8日 | | 8月22－27日 | 

 | 孵化 | | 8月2－6日 | | 8月8－13日 | | 8月26－9月1日 | 
三、防治意见：1、防治对象田：一季晚稻田、二晚田及对应制种田。2、防治时间：中稻田结合保穗药进行防控，晚稻田防治时间第一次为8月11－16日，第二次为8月20－25日。3、防治药剂：对枯鞘丛率达8％以上的田块施药防治，生物农药推荐苏云金杆菌、多杀霉素；化学农药可用甲氧虫酰肼、丁虫腈、杀虫双、杀虫单、四唑虫酰胺、溴氰虫酰胺、喹硫磷、乙基多杀·甲氧虫酰。4、施药时田间保5－7厘米水层3－5天。优先使用生物农药，生物农药要在防治适期前提早2－3天使用，注意轮换用药，苗弱的可加入叶面肥。稻田禁用含拟除虫菊酯类成分农药，慎用有机磷类农药。水稻分蘖期尽量少用甲氨基阿维菌素苯甲酸盐、阿维菌素。阿维菌素、氯虫苯甲酰胺每季水稻使用次数不超过1次。农药包装废弃物应回收处理，不得丢弃田间地头。
