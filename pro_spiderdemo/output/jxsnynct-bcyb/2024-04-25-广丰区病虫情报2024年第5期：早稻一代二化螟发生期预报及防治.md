## 正文

根据冬后病虫基数，品种布局，栽培管理条件等因素，参考长期天气预报和病虫历史资料综合分析：1、病虫基数：二化螟冬后基数高，全区均值2400条/亩，比上年1921条/亩高24.93%。预计今年早稻二化螟偏重发生。据广丰区农业农村局及部分乡镇农技站调查，目前越冬二化螟已开始羽化，一代二化螟将陆续在田间发生为害。根据田间调查情况，结合气候等因素综合分析，预计今年一代二化螟发生期如下:

 | 发育时期 | | 羽&nbsp;&nbsp;化 | | 孵&nbsp;&nbsp;化 | 

 | 始盛期 | | 4月20日－4月22日 | | 5月1日－5月4日 | 

 | 高峰期 | | 4月23日－4月27日 | | 5月5日－5月10日 | 

 | 盛末期 | | 4月28日－5月1日 | | 5月10日－5月14日 | 
防治措施：1、防治标准：枯鞘丛率达8%的田块应立即施药防治。2、防治适期：5月10－22日，凡枯鞘丛率达8%的田块要立即开展防治，对轻发生的田块可挑治枯鞘枯心团。3、防治农药：每亩用5%阿维菌素100毫升兑水20－30公斤喷施。
