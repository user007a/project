## 正文

一、发生量预测根据冬后残存基数剥查，万年县二化螟田块亩残存虫量平均为18500条左右，冬后残存基数低于去年。因二化螟越冬寄主多，场所复杂，发育进度参差不齐，致使其发蛾期持续时间较长。结合耕沤灭螟工作全面开展以及绿色防控技术的大面积推广应用，预计万年县早稻一代二化螟中等发生，局部偏重发生，发生程度略轻于去年。二、发生期预报测报灯下与物联网监测点数据显示，4月21日—29日出现蛾峰，结合剥查稻桩内越冬代二化螟发育进度、灯下监测数据、近期气象条件及禾苗长势等因素综合分析，预报一代二化螟发生期如下：&nbsp; &nbsp; &nbsp;始盛期&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 高峰期&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;盛末期羽化 &nbsp;4月13日-19日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 4月25日-5月5日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 5月10日-15日孵化 &nbsp;4月23日-29日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;5月6日-16日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;5月20日-25日三、防治意见1、防治适期：5月8日-18日。2、防治标准：枯鞘丛率8%以下田块可挑治枯鞘团，达8%以上的田块进行全田防治。3、防治药剂：可选用生物农药苏云金杆菌、多杀菌素、短稳杆菌、阿维菌素等。化学农药可选用甲氧虫酰肼、甲氨基阿维菌素苯甲酸盐等。药后保寸水3—5天。二化螟常年发生较重区或抗药性高的区域应采取合理混配、轮换用药、交替使用的方式选择药剂。生物农药如苏云金杆菌防治二化螟应在卵孵化高峰期前2—3天施药为宜。重点选择使用“三高三低”（高含量，高活性，高防效，低毒性，低残留，低用量）农药。要落实“防早防小、压控基数”的策略。利用好卵孵化盛期至低龄幼虫期关键时期，防好一代二化螟，减轻中晚稻防治压力。四、防治方式：采用绿色防控技术（每亩放置一个二化螟诱捕器，诱杀雄娥，干扰成虫正常交配，减少田间有效卵量）与化学防治相结合的方式有效地控制二化螟发生为害，使用植保无人机等新型高效植保机械精准施药，扎实推进专业化统防统治，施药时务必添加增效助剂，提高农药利用率，达到有效防治病虫害的同时减少了农药用量。
