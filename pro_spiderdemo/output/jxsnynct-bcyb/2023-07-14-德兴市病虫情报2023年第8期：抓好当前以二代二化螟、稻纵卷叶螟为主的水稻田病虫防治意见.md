## 正文

一、一代二化螟发生情况：今年德兴市一代二化螟中等发生，相似于去年。自6 月下旬以来，卷叶螟蛾陆续迁入部分乡镇，随着一晚田禾苗快速生长，促使卷叶螟蛾大批量迁入及提供了大量产卵场所，高温时晴时雨的天气也十分有利于稻纵卷叶螟产卵与孵化，预计二代稻纵卷螟中等偏重发生，相似于去年，且有发生期较长、发生面积广的趋势。二、二代二化螟发生趋势预测：结合田间发育进度剥查、一代残存基数、病虫监测设备蛾量以及气象与历史资料等因素分析，预计今年德兴市二代二化螟中等略偏重发生态势，部分田块重发生，主要为害一季晚稻和二晚早栽早发田，发生时期长，具体情况为：始 盛 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 高 峰 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 盛 末羽化 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;6 月 18-23 日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;6 月 28 日-7 月 8 日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 7 月 13-20 日孵化 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;6 月 28-7 月 3 日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;7月 8 日-7 月 18 日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;7 月 23-30日（1）防治对象：主防二化螟、稻纵卷叶螟，兼治纹枯病、稻飞虱等。（2）防治适期及防治标准： 7 月11 日-18日；枯鞘丛率达8%以上的田块即用药防治。稻纵卷叶螟防治标准：百丛新虫苞达25个以上田块。（3）防治药剂：1、防二化螟、卷叶螟：可选用高含量的生物农药苏云金杆菌、多杀霉素、阿维菌素、短稳杆菌、金龟子绿僵菌等。化学农药可选用甲氧虫酰肼、氯虫苯甲酰胺、喹硫磷等，混配使用一些具有杀卵功效的农药。注：生物农药如苏云金杆菌防治二化螟应在卵孵化高峰期前 2—3 天施药为宜。2、防纹枯病：可选用井冈霉素或氟环唑·吡唑醚菌酯或已唑醇·噻呋酰胺或苯甲·嘧菌酯或苯甲·丙环唑等药剂。3、防稻飞虱：可选用苦参碱或吡蚜酮或呋虫胺或烯啶虫胺或三氟苯嘧啶等药剂。以上药剂可视田间病虫发生情况进行选择，混合用药，药后保存水3—5 天。四、防治方式采用绿色防控（性引诱剂诱蛾、稻鸭共养等方式）与化学防治相结合的方式更能有效地控制水稻重大病虫害的发生危害。各乡镇要积极组织开展病虫害统防统治，推广使用植保无人机等新型高效植保机械精准施药，推进专业化统防统治，提高农药利用率、防控效果和经济社会效益，减少农药使用量。施药时必须做好安全防护，要戴好口罩、穿好防护服，防止发生农药中毒。
