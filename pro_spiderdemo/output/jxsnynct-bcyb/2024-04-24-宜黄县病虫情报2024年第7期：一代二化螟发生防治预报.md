## 正文

一、越冬基数调查及发生程度预测全县植保人员在3月5-10日对二化螟越冬基数进行田间剥查，具体情况如下：冬后最高亩虫量为28800条，低于去年的38400条，亩平均虫量12510条，相似于去年的12970条，远高于亩虫量1000条大发生的标准。综合分析宜黄县品种布局、栽培管理、气象预报等因素，预测2024年宜黄县一代二化螟偏重发生，局部重发生，发生程度相似于去年。二、发育进度调查及发生期预测本站从4月1到4月25日对越冬二化螟的田间发育进度进行监测，受气温及耕作等影响，发育进度各田块表现差异较大，根据调查数据，结合历史资料及当前气象情况综合分析，对一代二化螟发育进度预测如下：

 | 化蛹 | | 4月4-11日 | | 4月11-18日 | | 4月25-5月2日 | 

 | 羽化 | | 4月14-21日 | | 4月21-28日 | | &nbsp;&nbsp;5月3-5月11日 | 

 | 孵化 | | 4月26-5月2日 | | 5月2-8日 | | 5月13-20日 | 
预计今年一代二化螟孵化进度较去年推迟1-2天。三、防治意见1、防治对象田：早稻田、春制种田、早播中稻秧田。2、防治适期：第一次5月5-13日，隔8-12天再施药一次。3、防治方法及用药：1）、大田及时翻耕灌深水5-7天灭蛹灭幼虫，及时安装性诱剂、杀虫灯；2）、秧田打好送嫁药；3）、对枯鞘丛率达8%以上的田块进行精准施药，生物农药推荐用苏云金杆菌、多杀霉素；化学农药可用甲氧虫酰肼、丁虫腈、杀虫双、杀虫单、溴氰虫酰胺、喹硫磷、乙基多杀·甲氧虫酰。施药时田间保水层5-7厘米，并保持水层3-5天，秧苗弱的可加入叶面肥。优先使用生物农药，生物农药要在防治适期前提早2-3天使用，注意轮换用药。注：稻田禁用含拟除虫菊酯类成分农药，慎用有机磷类农药。水稻分蘖期尽量避免用甲氨基阿维菌素苯甲酸盐、阿维菌素。阿维菌素、氯虫苯甲酰胺每季水稻使用次数不超过1次。
