## 正文

一、二代二化螟发生实况今年二代二化螟主要为害中迟熟早稻田，中稻田及相对应的制种田，在早稻田上中等偏轻发生，造成枯心（枯穗）率一般在0．1－0．3％，高的达2．1％以上。在中稻田中等发生，造成枯鞘率一般为1－5％，高的为15％以上。当前田间调查：中稻二代二化螟形成枯心率一般0—0．5％，高的达2．5％以上，晚稻田枯鞘丛率一般为0—2％，高的达5％以上，田间平均亩虫量5845条，最高14220条。二、三代二化螟发生预测结合中、晚稻苗情，综合分析我县品种布局、栽培管理、气象预报等因素，预测2025年我县三代二化螟中等发生，发生程度相似于去年。预测二代二化螟发育进度如下：
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 7月20－25日 | | 7月27－8月2日 | | 8月15－20日 | 

 | 羽化 | | 7月25－30日 | | 8月2－7日 | | 8月21－26日 | 

 | 孵化 | | 8月1－5日 | | 8月7－12日 | | 8月26－9月1日 | 
三、防治意见：1、防治对象田：一季晚稻田、二晚田及对应制种田。2、防治时间：中稻田结合保穗药进行防控，晚稻田防治时间第一次为8月10—15日，第二次为8月20－25日。3、防治药剂：对枯鞘丛率达8％以上的田块施药防治，生物农药推荐用苏云金杆菌、多杀霉素；化学农药可用甲氧虫酰肼、丁虫腈、杀虫双、杀虫单、四唑虫酰胺、溴氰虫酰胺、喹硫磷、乙基多杀·甲氧虫酰。施药时田间保水层5－7厘米，并保持水层3－5天，秧苗弱的可加入叶面肥。优先使用生物农药，生物农药要在防治适期前提早2－3天使用，注意轮换用药。
