## 正文

一、田间病虫发生实况根据新干县田间病虫监测调查：部分一晚和早栽二晚二化螟为害较重，一晚田枯心率高的达11.8%，一般为0.58%，早栽二晚枯鞘率高达2.02%，一般为0.14%；太阳能虫情测报灯下蛾量7月17日65只、7月18日68只、7月19日153只、 7月20日35只 、 7月21日24只；根据7月31日田间二化螟发育进度剥查发现，发育进度很不整齐，世代重叠现象严重,给防治带来困难；纹枯病在一晚田中也开始扩展蔓延，病丛率高的达24%，一般为2%，稻飞虱百丛虫量高达124只,一般为20-50只。目前田间卷叶虫亩蛾量一般为0-20只。当前新干县二晚已陆续进入返青分蘖期，大部分禾苗长势良好，同时也是最易遭受钻心虫、卷叶虫、稻瘟病等主要病虫混合危害，希望广大农民朋友应加强管理，及时做好防治工作。二、防治意见㈠防治时间：8月5～13日(早抛栽早打药，晚抛栽晚打药，达到防治指标立即施药)㈡防治对象田：全县所有的一晚田和二晚田。一晚田主攻钻心虫、稻飞虱，卷叶虫、兼治纹枯病、稻瘟病和南方黑条矮缩病；二晚田主防钻心虫、卷叶虫，兼治稻飞虱、稻瘟病和纹枯病。㈢防治指标：①钻心虫：枯鞘丛率达8%以上;②卷叶虫：百丛新虫苞达30个以上;③纹枯病：丛病率达20%以上;④稻飞虱：百丛飞虱1500只以上; &nbsp;⑤稻瘟病：发现有发病中心三、防治方法：（亩可选用以下一种药剂兑水60斤喷雾进行防治）㈠防治稻瘟病药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）1000亿芽孢/克枯草芽孢杆菌 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ② 6%春雷霉素③ &nbsp;75%三环唑 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;④ 40%稻瘟灵㈡防治纹枯病可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）⑴20%井冈霉素 &nbsp; &nbsp; &nbsp; &nbsp; ⑵ &nbsp;20%井冈蜡芽菌；(3) 10%己唑醇; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (4) 30%苯甲·丙环唑㈢防治稻纵卷叶螟可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）⑴ &nbsp;5%阿维菌素 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;⑵ 72%丙溴磷； &nbsp; ⑶ &nbsp; 20%氯虫苯甲酰胺㈣防治稻飞虱可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）⑴ &nbsp;50%吡蚜酮; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(2) &nbsp;70%吡虫啉；（3）25%噻虫嗪； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; （4） 20%呋虫胺.㈤防治 二化螟药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）① 16000IU/毫克苏云金杆菌可湿性粉剂； &nbsp; &nbsp; &nbsp; &nbsp;②5%阿维菌素;③5%甲维盐； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ④90%杀虫单
