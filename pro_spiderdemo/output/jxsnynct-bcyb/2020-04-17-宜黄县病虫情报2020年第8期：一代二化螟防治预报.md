## 正文

一、越冬基数调查及发生程度预测宜黄县植保植检站3月8-14日对二化螟越冬基数进行田间调查，具体情况如下：冬后最高亩虫量为22400条，高于去年的7200条，亩虫量平均4480条，高于去年的4280条，增加4.67%，且虫量高于亩虫量1000条大发生的标准。综合分析，预测2020宜黄县一代二化螟偏重发生，发生程度略重于去年，少量稻田重发生。二、发育进度调查及发生期预测本站从3月30到4月15日对越冬二化螟的田间发育进度进行监测，根据调查数据，结合历史资料及当前气象情况分析，对一代二化螟发育进度预测如下：
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 4月2-7日 | | 4月9-14日 | | 4月18-23日 | 

 | 羽化 | | 4月12-18日 | | 4月19-25日 | | 4月28-5月3日 | 

 | 孵化 | | 4月22-5月28日 | | 4月29-5月5日 | | 5月8-15日 | 

三、防治意见预计今年二化螟发育进度较去年提早1-3天。
1、防治对象田：早稻田、春制种田、早播中稻秧田。2、防治适期：第一次5月1-5月8日，第二次为5月15-20日。3、防治方法及用药：1）大田在4月20日前翻耕灭蛹，及时安装性诱剂、杀虫灯；2）秧田打好送嫁药；3）对枯鞘丛率达8%以上的田块，每亩用16000IU/毫克苏云金杆菌可湿性粉剂300-400克或5%阿维菌素乳油 50-100克或20%氯虫苯甲酰胺悬浮剂10-15毫升或40%三唑磷乳油100-150毫升或5%多杀·甲维盐悬浮剂 30-50克兑水30－45公斤喷雾防治。施药时田间保水层5-7厘米，并保持水层3-5天，秧苗弱的可加入叶面肥。注意轮换用药，生物农药要在防治适期前提早2-3天使用。
