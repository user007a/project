## 正文

一、田间病虫发生实况1、二化螟：根据新干县植保植检站田间调查，一代残存虫量高达12000多条，一般为4500条，一季稻枯鞘丛率一般为4%—16%、高的达25%。二代二化螟在7月中旬有一次为害高峰，主要为害一季稻、早栽晚稻。预测第二代二化螟偏重发生、局部重发生，各地应加强监测，在二化螟枯鞘丛率达8%时及时施药防治。2、两迁害虫（卷叶虫和稻飞虱）：受近期降雨影响，两迁害虫不断迁入。7月8日田间卷叶虫赶蛾最高亩蛾量1200只，一般20-40只；稻飞虱百丛虫量高达420只，平均260只。随着早稻收割、外地迁入，虫量还会上升。3、稻瘟病：目前新干县植的一季稻糯稻、丝苗等个别田块发生稻瘟病，近期降雨适温高湿，稻瘟病流行风险很大。4、纹枯病：据新干县植植保植检站和乡镇农技站田间调查，一季稻病丛率一般为16%-25%，个别田块高达51%；发生面积、发生程度逐渐上升。5、洪水过后细菌性基腐病易发生。二、防治意见1、防治对象田：一季晚稻、早栽晚稻、迟熟早稻。2、防治时间及策略：防治时间： 7月15—20日施药防治。田间病虫发生达到防治指标时立即施药防治。防治指标： &nbsp;二化螟：枯鞘丛率8%。 &nbsp;稻纵卷叶螟：百丛禾出现卷叶新苞60个。稻飞虱：百丛虫量1000只。稻瘟病：出现发病中心或破口抽穗初期。 &nbsp; &nbsp; 纹枯病：病丛率20%。迟熟早稻及一季稻： &nbsp; 主攻稻纵卷叶螟、二化螟，兼治稻飞虱、纹枯病、稻瘟病。早栽晚稻： 主攻稻纵卷叶螟、二化螟，兼治稻飞虱、稻蓟马、稻瘟病，预防南方黑条矮缩病。三、防治方法：（亩可选用以下一种药剂兑水60斤喷雾进行防治1、防治二化螟药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）① 16000IU/毫克苏云金杆菌可湿性粉剂300-400克； &nbsp; &nbsp; &nbsp; &nbsp;②5%阿维菌素100-150毫升;③5%甲维盐30-50克； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ④90%杀虫单100-200克2、防治稻纵卷叶螟可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）①&nbsp;5%阿维菌素80-100克 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;② 72%丙溴磷50-75克；③20%氯虫苯甲酰胺10-15毫升3、防治稻飞虱可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）①50%吡蚜酮16-20克; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;②70%吡虫啉5-10克；③25%噻虫嗪15-25克； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ④20%呋虫胺 30-50克.4、防治稻瘟病药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）① 1000亿芽孢/克枯草芽孢杆菌15-25克 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;②6%春雷霉素30-40克;③75%三环唑30-50克； &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;④40%稻瘟灵100-150克5、防治纹枯病可以选用药剂（亩可选用以下一种药剂兑水60斤喷雾进行防治）①20%井冈霉素50-70克..... &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;②20%井冈蜡芽菌100-120毫升；③10%己唑醇45-50毫升; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ④30%苯甲·丙环唑15-20毫升6、防治细菌性基腐病药剂：撒施石灰、草木灰，喷施噻菌铜、噻唑锌等药剂。
积极做好二晚南方水稻黑条矮缩病预防工作据分析预测，今年新干县二晚南方水稻黑条矮缩病有发生加重、发生范围扩大的趋势。各地要积极做好预防工作，一是药剂拌种，选用50%吡蚜酮10克，或25%噻虫嗪20克或10%吡虫啉15-20克拌2斤干稻种，在种子催芽露白后拌均匀即可播种；二是在秧苗二叶一心期和移（抛）栽前2-3天喷药，选用10%醚菊酯或25%噻虫嗪或50%吡蚜酮，加2%宁南霉素。
