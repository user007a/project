## 正文

一、三代发生实况三代田间亩活虫残存密度高的1780条，一般的50-500条，平均312条（去年同期178条）， 卷叶率高的1.85%，一般的0.1-0.70%，平均0.35%（去年同期0.15%），三代发生为害程度重于去年。8月份以来田间赶蛾未见明显外地虫源迁入。二、四代发生期预报近期对本地三代卷叶螟发育进度进行调查，8月14日长冈化蛹率为31.82 %，羽化率为4.55%，8月15日高兴化蛹率为41.18%，羽化率为5.88%，现根据其发育进度，结合历史资料及气象分析，以中发地区为例，对本地四代发生期预报如下：发蛾盛期：8月16-25日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;发蛾高峰：8月18-20日孵化盛期：8月22-31日 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;孵化高峰：8月24-26日三、发生特点及危害程度今年三代本地虫源发生期较去年迟4天左右，田间残留基数较高，预计四代中等偏重发生，局部重发生，在防治不力或不防治情况下，晚稻剑叶被害率高的可达50%以上，另外，8月下旬至9月份受台风或冷空气影响，外地虫源迁入兴国县的可能性还较大，为此各乡（镇）在指导农户防治好近期卷叶螟的同时，密切注意卷叶螟的迁飞动态，及时指导农户搞好防治，确保剑叶不受危害。四、防治意见1、防治时间：8月25-27日。2、防治对象田：晚稻早中熟青绿茂盛田块。3、防治指标：凡每百丛禾有水稻束叶尖60个的田块应立即用药防治。4、防治药剂：（1）亩用5.7%甲维盐水分散粒剂20克+5%虱螨脲悬浮剂50毫升。（2）亩用5%阿维菌素乳油50毫升+5%虱螨脲悬浮剂50毫升。（3）亩用30%茚虫威悬浮剂12克+5%虱螨脲悬浮剂50毫升。任选以上—配方兑水40-50公斤于下午4时后喷雾。
