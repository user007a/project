## 正文

一、冬后基数情况及发生程度预测3月8－12日，本站组织全县植保人员对二化螟冬后基数进行田间剥查，结果如下：冬后最高亩虫量为36800条，低于去年的58400条，亩平均虫量11625条，低于去年的21138条，但仍远超过亩虫量1000条大发生的标准。综合分析预测2026年我县一代二化螟偏重发生，发生程度略轻于去年。二、发育进度调查及发生期预测植保人员从4月1到4月20日对冬后二化螟的田间发育进度进行监测，受环境及耕作等因素影响，各田块发育进度表现差异较大，根据调查数据，结合历史资料及当前气象情况综合分析，对一代二化螟发育进度预测如下：
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 4月5－10日 | | 4月12－17日 | | 4月25－30日 | 

 | 羽化 | | 4月15－20日 | | 4月22－27日 | | 5月5－ 10日 | 

 | 孵化 | | 4月25－30日 | | 5月2－7日 | | 5月15－20日 | 
预计今年一代二化螟孵化进度较去年提早3－4天。三、防治意见1、防治对象田：早稻田、春制种田、早播中稻秧田。2、防治适期：第一次5月2－7日，隔8－10天再施药一次。3、防治方法及用药：1）大田及时翻耕灌深水5－7天灭蛹灭幼虫，及时安装性诱剂、杀虫灯；2）秧田打好送嫁药；3）对枯鞘丛率达8％以上的田块进行精准施药，生物农药推荐用苏云金杆菌、多杀霉素；化学农药可用甲氧虫酰肼、丁虫腈、杀虫双、杀虫单、溴氰虫酰胺、喹硫磷、乙基多杀·甲氧虫酰、四唑虫酰胺等。施药时田间保水层5－7厘米，并保持水层3－5天，秧苗弱的可加入叶面肥。优先使用生物农药，生物农药要在防治适期前提早2－3天使用，注意轮换用药。
