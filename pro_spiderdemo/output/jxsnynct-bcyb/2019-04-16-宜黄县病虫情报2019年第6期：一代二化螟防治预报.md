## 正文

一、越冬基数调查及发生程度预测　　宜黄县植保植检站3月3-10日对二化螟越冬基数进行田间调查，具体情况如下：冬后亩虫量平均4280条,低于去年的7521条，减少43.09%，最高亩虫量为7200条，低于去年的19200条，虫量高于亩虫量1000条大发生的标准。　　综合分析，预测2019宜黄县一代二化螟偏重发生，发生程度略轻于去年，少量稻田重发生。　　二、发育进度调查及发生期预测　　根据本站对二化螟的田间发育进度调查数据，结合历史资料及当前气象情况分析，对一代二化螟发育进度预测如下：&nbsp; 
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 4月6日-10日 | | 4月12日-17日 | | 4月21-26日 | 

 | 羽化 | | 4月18日-23日 | | 4月25日-30日 | | 5月2日-7日 | 

 | 孵化 | | 4月28日-5月3日 | | 5月5日-10日 | | 5月12日-17日 | 
　　预计今年二化螟发育进度与去年相似。　　三、防治意见　　1、防治对象田：早稻田、春制种田、早播中稻秧田。　　2、防治适期：第一次5月1-5月8日，第二次为5月15-20日。　　3、防治方法及用药：1）、大田在4月20日前翻耕灭蛹，及时安装性诱剂、杀虫灯；2）、秧田打好送嫁药；3）、在防治适期每亩用16000IU/毫克苏云金杆菌可湿性粉剂300-400克（生物农药应适当提前2-3天用药）或5%甲维盐水分散粒剂25-35克或40%三唑磷乳油100-125毫升或24%甲氧虫酰肼悬浮剂30-50克兑水30－45公斤喷雾防治。施药时田间保水层5-7厘米，并保持水层3-5天，秧苗弱的可加入叶面肥。
