## 正文

一、越冬基数调查及发生程度预测本站3月15-20日对二化螟越冬基数进行田间调查，具体情况如下：冬后亩虫量平均7521条,低于去年的11954条，减少37.08%，最高亩虫量为19200条，低于去年的65600条。预测今年我县一代二化螟中等发生，发生程度轻于去年，少量稻田重发生。二、发育进度调查及发生期预测根据本站对二化螟的田间发育进度调查数据，结合历史资料及当前气象情况分析，对一代二化螟发育进度预测如下：
 | 时期 | | 始盛期 | | 高峰期 | | 盛末期 | 

 | 化蛹 | | 4月5-10日 | | 4月12-17日 | | 4月21-26日 | 

 | 羽化 | | 4月15-20日 | | 4月21-26日 | | 4月30-5月5日 | 

 | 孵化 | | 4月23-28日 | | 4月30-5月5日 | | 5月10-17日 | 
预计今年二化螟发育进度与去年相似。三、防治意见1、防治对象田：早稻田、春制种田、早播中稻秧田。2、防治适期：第一次5月3-5月8日，第二次为5月15-20日。3、防治方法及用药：1）、大田在4月20日前翻耕灭蛹；2）、秧田打好送嫁药；3）、在防治适期每亩用16000IU/毫克苏云金杆菌可湿性粉剂300-400克或5%甲维盐水分散粒剂25-35克或40%三唑磷乳油100-125毫升或24%甲氧虫酰肼悬浮剂30-50克兑水30－45公斤喷雾防治。施药时田间保水层5-7厘米，并保持水层3-5天，秧苗弱的可加入叶面肥。
