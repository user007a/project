## 正文

一、发生情况及趋势分析冬后田间稻桩剥查，二化螟平均亩活虫8900条，比去年减少11.49%，高的32360条，与去年接近。冬闲水田耕沤灭螟措施到位，蛹期遇低温多雨，死亡率较高，但其越冬场所分散，逃逸能力强，部分地方有效虫源仍较多，预计一代二化螟总体中等发生，部分偏重发生，相似于去年。二、发生适期预报4月18-19日，二化螟发育进度调查，化蛹率55.74%；测报灯诱及性诱成虫观察，4月中旬陆续进入盛蛾期，4月16-20日、4月26日-5月3日出现蛾峰。通过发育进度计算，结合温度以及历史资料等因素分析，预计今年一代二化螟发育进度如下：&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 始 &nbsp; &nbsp;盛&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 高 &nbsp; &nbsp;峰&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 盛 &nbsp; &nbsp;末羽化 &nbsp;4月17-22日 &nbsp; &nbsp; &nbsp;4月27日-5月5日 &nbsp; &nbsp; &nbsp;5月9-12日孵化 &nbsp;4月27日-5月2日 &nbsp; &nbsp;5月7-15日 &nbsp; &nbsp; &nbsp; &nbsp;5月18-21日发生期相似于去年。三、防治意见1、防治对象：主治二化螟，兼治稻蓟马、大螟等2、防治适期及防治标准：在5月8-14日枯鞘丛率达8% (或枯鞘株率0.5%)以上的早稻田即应用药防治，低于防治标准的可不防或挑治枯鞘团。3、防治药剂：（1）生物农药：选用多杀霉素、苏云金杆菌、阿维菌素等；（2）化学农药：选用甲氨基阿维菌素苯甲酸盐、甲氧虫酰肼、丁虫腈、杀虫单、溴氰虫酰胺、乙基多杀•甲氧虫酰、阿维•甲虫肼、多杀•甲维等。选用一至二种，对水均匀喷雾。4、注意事项：注意保护田间天敌，优先使用生物农药，稻田禁止使用含拟除虫菊酯类成分农药，慎用有机磷类农药，尤其是在水稻前期，以免破坏农田生态环境，引发害虫再猖獗。
