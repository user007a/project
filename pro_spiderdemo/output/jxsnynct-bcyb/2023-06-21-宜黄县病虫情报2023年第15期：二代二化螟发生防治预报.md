## 正文

一、一代二化螟残存情况及二代发生程度预测植保技术人员对一代二化螟残存基数进行田间剥查，具体情况如下：一代二化螟残存最高亩虫量为24400条，高于去年的19200条，亩平均虫量10960条，高于去年的8360条。综合分析宜黄县品种布局、栽培管理、气象预报等因素，预测2023年宜黄县二代二化螟中等偏重发生生，发生程度重于去年。二、发育进度调查及发生期预测本站从6月10到6月20日对一代二化螟的田间发育进度进行监测，受气温及耕作等影响，各田块发育进度表现差异较大，根据调查数据，结合历史资料及当前气象情况综合分析，对一代二化螟发育进度预测如下：

 | 羽化 | | 6月20-25日 | | 6月27-7月3日 | | 7月15-20日 | 

 | 孵化 | | 6月25-30日 | | 7月2-8日 | | 7月20-25日 | 
预计今年二代二化螟孵化进度较去年提早1-2天。三、防治意见1、防治对象田：迟熟早稻田、一季晚稻田、二晚秧田、早栽二晚田及对应制种田。2、防治适期：第一次7月2-8日，第二次为7月15-20日。3、防治方法及用药：1）、及时更换二化螟诱芯；2）、晚稻秧田要适时打好送嫁药；3）、对枯鞘丛率达8%以上的田块施药，生物农药推荐用苏云金杆菌、多杀霉素；化学农药可用甲氧虫酰肼、丁虫腈、杀虫双、杀虫单、溴氰虫酰胺、喹硫磷、乙基多杀·甲氧虫酰。施药时田间保水层5-7厘米，并保持水层3-5天，秧苗弱的可加入叶面肥。优先使用生物农药，生物农药要在防治适期前提早2-3天使用，注意轮换用药。注：稻田禁用含拟除虫菊酯类成分农药，慎用有机磷类农药。水稻分蘖期尽量少用甲氨基阿维菌素苯甲酸盐、阿维菌素。阿维菌素、氯虫苯甲酰胺每季水稻使用次数不超过1次。
