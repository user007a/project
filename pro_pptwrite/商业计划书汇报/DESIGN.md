# DESIGN.md · 叁竹 × 湖外 校企合作商业计划书

> 风格来源：`PPT风格分析.md`（深绿 + 浅薄荷白 + 海军蓝；卡片式、圆形编号、弧形 wave 分隔、胶囊标签）。
> 调性：商务正式 / 康养绿意 / 高校产业 / 数据驱动。

## 1. 画布与全局母版（A/B/C 三区，px）
- 画布：1280 × 720，16:9。
- **A 标题块**：0–110px，左 padding 60px，主标题 34px bold，左侧 6px 深绿竖条装饰。
- **B 内容区**：110–662px，左右 padding 60px，可用高 552px。
- **C 页脚条**：662–720px，左 `叁竹 × 湖外 校企合作商业计划书`，右 `NN / 27` 页码，14px 灰字。
- 封面 / 章节扉页 / 结束页允许自定义全屏版式（省略 C 区页码或保留右下页码）。

## 2. 颜色系统（≤4 品牌 hex + 中性）
| 角色 | HEX | 用途 |
|---|---|---|
| 主色 深绿 | `#0F5C46` | 标题、章节大字、强调块、主视觉底 |
| 辅色 海军蓝 | `#0A2B4D` | 弧形 wave、深底反白、次级强调 |
| 强调 亮绿 | `#2E9E78` | 巨型数字、核心数据、焦点高亮、进度 |
| 文本 墨绿黑 | `#1C2B24` | 正文、标题文字 |
| 中性 | `#FFFFFF` / `#F4F9F6`(浅薄荷底) / `#5C6B63`(灰) / `#D9E8E1`(浅绿描边) | 背景、卡片、页脚、分隔线 |

### 2.1 色彩面积分配（每页在 B 区遵守）
- 常规内容页：主色 ≤ 55%（含浅绿卡片底），辅色 ≤ 25%，强调色 ≤ 8%（只落焦点）。
- Hero / 章节扉页：主+辅 ≥ 70%（全屏渐变底），强调色 10–18%。
- 全篇差异：封面/扉页/结束用深底；内容页用浅薄荷白底 + 白卡，避免每页同比例。

### 2.2 渐变与半透明
- 全屏底（封面/扉页/结束）：`linear-gradient(135deg, #0A2B4D 0%, #0F5C46 100%)`。
- 弧形 wave：底部叠加 `rgba(255,255,255,0.06)` 的 Path 弧带，深底上做层次。
- 卡片：`background:#FFFFFF`，`boxShadow:0 4px 20px rgba(15,92,70,0.10)`，圆角 14。
- 浅绿卡：`background:rgba(46,158,120,0.10)`，描边 `1px solid #D9E8E1`。
- 文字蒙版：深底上白字加 `textShadow:0 2px 10px rgba(0,0,0,0.25)`。

## 3. 字体系统（2 套字族）
- 中文/标题：`"Source Han Sans SC","Microsoft YaHei",sans-serif`（标题 bold 700，正文 regular 400）。
- 西文/数字：`"DIN Alternate","Inter","Helvetica Neue",sans-serif`（巨型数字用 700）。
- 字号阶梯：封面主标 64 / 章节大字 72 / 巨型数据 96 / 页面主标 34 / 卡片小标 24 / 正文 21 / 注释 16 / 页码 14。

## 4. 信息密度门禁
- 内容页正文 ≥ 180 字，卡片每卡 ≥ 100 字（合计≥300）；主视觉占 B 区 ≥ 30%。
- 常规页留白 ≤ 35%；Hero/扉页不受限。
- 容器填充率 ≥ 85%：卡片内三段（标题/正文/尾部标签）用 `justifyContent:space-between` 钉底。

## 5. 配图系统（摄影图 + 矢量图表混合）
- **L1 主视觉**：封面/章节扉页/结束页使用全屏校园摄影图 + 深绿半透明蒙版 + 弧形 wave（参考 1.png）。内容页使用实景配图、Chart/SVG 流程图/时间轴作 L1。
- **L2 支撑**：章节序号大圆徽、要点图标卡、数据卡片、实景小图。
- **L3 角标**：全篇统一页脚文字 + 圆形序号徽标，位置一致。
- 图片来源：6 张 ImageGen 生成的校园/康养摄影图，存放于 `assets/`；封面背景以 1.png 为参考进行图生图，确保校门视觉一致。
