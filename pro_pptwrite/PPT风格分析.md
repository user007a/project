# PPT 风格提炼：叁竹 × 湖外 校企合作商业计划书

## 一、整体风格关键词
- **商务正式 + 高校/康养产业气质**：适合校企战略合作、商业计划书、产教融合汇报。
- **简洁现代**：扁平化、卡片式布局、大留白、信息层级清晰。
- **绿色主调**：呼应“养老照护、健康、康养”主题，传递信任、生态、可持续感。
- **数据/结论可视化**：关键数字、占比、估值用色块/加粗突出，流程用箭头流程图表达。

## 二、配色方案（近似值）
| 用途 | 颜色描述 | 近似 HEX | 使用场景 |
|---|---|---|---|
| 主色（深绿） | 深森林绿/墨绿 | `#0F5C46` ~ `#1A4D3E` | 大标题、章节编号、重点强调文字、顶部数据条 |
| 辅色（海军蓝） | 深蓝 | `#0A2B4D` | 标题页/章节过渡页的弧形分割带 |
| 背景色 | 极淡薄荷白 | `#F8FBFA` | 正文页大面积背景 |
| 卡片色 | 淡绿灰 | `#F0F7F4` ~ `#EAF5F1` | 圆角内容卡片底色 |
| 点缀色 | 浅绿 | `#4AAD8C` ~ `#6BC4A6` | 小标签、圆形编号背景、流程图高亮块 |
| 正文字色 | 深灰/近黑 | `#333333` ~ `#1A1A1A` | 正文段落 |
| 反白字 | 白色 | `#FFFFFF` | 深绿/深蓝色块上的文字 |

## 三、字体特征
> 注：截图无法直接识别字体文件，以下为视觉特征与推荐字体。

- **标题字体**：粗黑/粗圆无衬线，笔画饱满，视觉重量大。
  - 推荐：思源黑体 Heavy / 阿里巴巴普惠体 Bold / 微软雅黑 Bold
- **章节编号字体**：大号粗体数字，如 `01`、`02`，字形方正。
  - 推荐：DIN / Montserrat / Oswald Bold，或与标题同字族 Bold
- **正文字体**：常规无衬线，清晰易读。
  - 推荐：思源黑体 Regular / 微软雅黑 / 阿里巴巴普惠体 Regular
- **数字/金额突出**：同标题字族，加粗、放大、使用主色。

## 四、版式与组织

### 1. 封面页
- 顶部：日期（`2026/08/16`）居中。
- 中部：主标题大号白色粗体，分两行居中；背景为校园大门照片 + 深绿半透明蒙版。
- 中下部：深蓝色弧形 wave 分隔带，上方放置校徽/Logo。
- 底部：汇报人信息。

### 2. 目录页
- 标题：左侧 `报告纲要` + 细横线装饰。
- 布局：2 列 × 5 行的卡片网格。
- 卡片：圆角矩形，内部为 `大编号 01` + `标题` + `一行副标题`。
- 编号：深绿色、字号大、字重粗。

### 3. 章节过渡页
- 背景：同封面（校园照片 + 深绿蒙版）。
- 装饰：深蓝色弧形 wave。
- 中心：超大圆形徽章，内含 `01` 编号；下方为章节标题。

### 4. 内容页（双栏卡片 + 图片）
- 顶部：左对齐大标题，可加浅色小竖线装饰。
- 左侧：上下两个圆角卡片，分别带圆形编号 `01`、`02` 和小标题。
- 右侧：大矩形实景图片 + 底部圆角总结卡片（含“核心判断”标签）。
- 强调：关键词用主色加粗高亮（如：养老照护、行业前三、6000 人）。

### 5. 数据/方案页
- 顶部通栏：深绿色横幅，白色大字展示核心数据，如：
  `投前估值 3000万元 | 湖外出资 1200万元 | 占股 40%`
- 中部：三列卡片（股权架构 / 估值逻辑 / 资金投向），卡片标题下划线装饰。
- 底部：横向流程图，6 个步骤用箭头串联，关键步骤用主色填充，其余用浅色。

## 五、图形与组件
- **圆角矩形卡片**：作为主要信息容器，圆角半径较大，边框细或无边框，轻微阴影。
- **圆形编号徽章**：
  - 章节过渡页：大号带圆环的 `01`。
  - 内容页列表：小号实心圆内嵌数字。
- **弧形 wave**：深蓝色曲线，用于分割封面/过渡页的图片区与文字区。
- **小标签（Pill）**：圆角胶囊形，如 `一方需要转型`、`核心判断`，使用浅绿/浅蓝底色。
- **流程箭头**：横向 6 步流程，箭头连接，数字编号在方块内。
- **Logo/校徽**：圆形校徽，置于封面弧形 wave 上方，尺寸中等。

## 六、可复用的风格公式
1. **背景**：浅薄荷白底 + 深绿主色 + 深蓝装饰弧线。
2. **标题**：左对齐或居中，深绿色，粗体，字号大。
3. **信息容器**：圆角卡片 + 大编号 + 小标题 + 正文 bullet。
4. **数据高亮**：把核心数字放进深绿色通栏，白色反白字。
5. **流程表达**：横向步骤卡片 + 箭头串联，重点步骤主色填充。
6. **图片使用**：康养/校园实景图，配合半透明蒙版，保证文字可读。
